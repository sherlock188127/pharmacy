🔬 膠體系統類型 ▶
依分散相與分散媒親和性分類
類型特性電解質影響
一、親溶媒性膠體（Lyophilic）分散相與分散媒有吸引力，產生媒合（solvation）；若溶媒為水則稱水合（hydration）；熱力學穩定系統一般仍安定；高濃度電解質 → 鹽析
二、厭溶媒性膠體（Lyophobic）分散相對分散媒吸引力小，粒子外圍無溶劑包覆；熱力學不穩定，需靠電荷安定；常需加入非離子性界面活性劑或保護性膠體極少量電解質就不穩定
三、結合膠體（Association colloid）亦稱兩性膠體（amphiphilic），兼具 lyophilic 與 lyophobic；≥50 個 surfactant 單體凝集成 micelle（直徑約 50 Å）；肉眼下澄清，屬單相系高濃度電解質 → 鹽析
一、親溶媒性膠體 — sol / gel / jellies
  • 大的有機分子與分散相分子媒合 → 形成 sol（溶膠），濃度越高黏性越大
  • 濃度夠高時，質粒彼此吸引，形成遍及液體各處之連續性網狀骨架 → 固化形成 gel（凝膠） 或 jellies（凍膠）
  • Jellies 是凝膠的一種，結構的黏性間質中含高比例液體（通常為水）
    ・例：sodium bentonite 或 pectic acid 2–3% 即可使 97–98% 之水固定不動
  • 凍膠通常由膠凝劑（gelling agent）如 tragacanth 或 CMC 於藥物水溶液中形成澄明均質半固體，易受微生物污染，需防腐
親溶媒性膠體依溶媒分類
類型溶媒例子
親油性膠體（Lipophilic / Oleophilic）有機溶劑或非極性油（mineral oil、benzene、CCl₄、cottonseed oil、peanut oil、lemon/peppermint essential oil）polystyrene、unvulcanized gum rubber 溶於 benzene；magnesium/aluminum stearate 溶於 cottonseed oil；activated charcoal 分散於 oils
親水性膠體（Hydrophilic）水acacia、gelatin、insulin、albumin、starch、bentonite、povidone 膨脹、分散或溶於水中
親水性膠體細分
  • True solutions：水溶性高分子（acacia、povidone）
  • Gelled solutions / gels / jellies：高濃度及/或溫度使高分子溶解度降低而形成（gelatin 和 starch 冷卻時；methylcellulose 加熱時）
  • Particulate dispersions：不形成分子溶液，維持小而分散之粒子（bentonite、microcrystalline cellulose）
親溶媒性膠體之製備
  • 可自然形成，簡單將物質溶於溶劑即可得到 sols
  • 簡單分散法：分散相加入分散媒，經濕潤再輕輕攪拌至完全分散
    ・若親和力不佳，可加入助懸劑（ex：BaSO₄ 於水中，需加入微晶纖維素或膠類協助分散）
  • 化學反應法：
    ・氫氧化鋁膠漿：Al₂(SO₄)₃ + Na₂CO₃ + H₂O △→ Al(OH)₃↓ + Na₂SO₄ + CO₂
    ・鎂乳膠漿：MgSO₄ + 2NaOH → Mg(OH)₂↓ + Na₂SO₄
二、厭溶媒性膠體依溶媒分類
類型例子
厭油性膠體（Lipophobic / Oleophobic）acacia、gelatin、insulin、albumin、cellulose 於非極性溶媒中
厭水性膠體（Hydrophobic）gum rubber、cholesterol、polystyrene 於水中（粒子僅稍微水合或完全不水合）
厭溶媒性膠體之製備（不能自然形成，需特殊方法）
方法說明例子
分散法
（wide particle size distribution）		超音波：以高強度超音波發生器分散—
膠體磨（colloidal mill）或微粉化機（micropulverizer）將粗粒子研細—
電極分散法：將電弧置於液中，電極金屬揮發成蒸氣再聚集成膠體粒子—
凝結法
（monodisperse sols）
使小於膠體之粒子凝集		降低溶解度：溶媒改變或降溫 → 高度過飽和系統 → 核仁（nuclei）形成及成長硫磺溶於酒精，倒入過量水中 → 形成 sol
還原法：金鹽、銀鹽、銅鹽、鉑鹽、汞鹽加入還原劑（磷、甲醛、沒食子酸）→ 金屬原子 → 帶電聚合物—

三、結合膠體（Association Colloid）— Micelle 與 CMC
CMC（Critical Micelle Concentration，臨界微膠粒濃度）： 濃度 < CMC → surfactant 以單體存在（大小 < 膠體） 濃度 ≥ CMC → 自然凝集形成 micelle（直徑約 50 Å） 光散射測 micelle 分子量： H(c−cCMC)/(τ−τCMC) = 1/M + 2B(c−cCMC) B = 0：非離子性 / 兩性 micelle（無交互作用） B > 0：離子性 micelle（排斥力，交互作用為正值） B < 0：多分散性 micelle 系統

💡 膠體的光學性質 ▶
Faraday-Tyndall Effect
  • 一束強光通過膠體溶液 → 光被膠體粒子散射 → 產生可見光錐
  • 粒子大小 > 入射光波長 → 反射；粒子大小 < 入射光波長 → 散射
  • 可見光波長 400–700 nm：真溶液太小（散射弱）；膠體 1–500 nm（散射）；粗分散系太大（只反射）
光散射測分子量
Hc/τ = 1/M + 2Bc τ：渾濁度（cm⁻¹） c：溶質濃度（g/cm³） M：平均分子量 B：交互作用常數 H = 32π³n²(dn/dc)² / (2λ⁴N) 截距 = 1/M → 求分子量 斜率 = 2B → 看溶質-溶劑交互作用 （不對稱粒子：散射光強度隨觀察角度改變 → 可估算粒子形狀及大小）

⚡ 膠體的動力學性質 ▶
布朗運動（Brownian Motion）
  • Robert Brown 提出：<5 μm 之粒子在顯微鏡下可見不規則運動
  • 液體分子不斷隨機碰撞膠體粒子 → 連續不規則運動
  • 與濃度無關；溫度↑ → 位移↑；粒徑↑ → 位移↓；黏度↑ → 位移↓
擴散（Diffusion）
Fick's First Law：J = dM/(S·dt) = −D·(dC/dx) 位移：x = √(2Dt) 擴散係數：D = kT/(6πrη) = RT/(6πrηN) 由 D 計算球形分子量： D = RT/(6πηN) · ∛(3/(4πN) · v/M) M：分子量 v：部分比容（≈ 溶質 1g 之體積，cm³/g） 擴散速率 ∝ 溫度↑、粒子小↓ 擴散速率 ∝ 1/黏度、1/粒子大小
滲透壓（Osmotic Pressure）
理想稀薄溶液：π = (cg/M)RT → π/cg = RT/M 聚合物：π/cg = RT/M + RTBcg 截距（RT/M）→ 求 M 斜率（RTB）→ 看溶質-溶劑交互作用： B > 0：溶劑-溶質引力大（媒合良好，solvation） B = 0：理想溶液 B < 0：溶質間引力大 → 會有沉澱 注意： ・僅適用於親溶媒系統（大分子溶液或 micelle） ・厭溶媒系統：對等離子也能增加滲透壓 → 測得分子量會太小 ・膠體分散系滲透壓常太小，不能準確測量
沉降作用（Sedimentation）— Stokes' Law
v = 2r²(ρ−ρ₀)g / 9η = d²(ρ−ρ₀)g / 18η r：半徑 d：直徑 ρ：粒子密度 ρ₀：液體密度 g：重力加速度 η：液體黏滯係數 假設：稀薄理想分散系；大小均勻球形質粒；層流（無亂流）；各粒子不互相干擾 儀器：Andreasen pipette v = h/t → dst = √(18ηv / (ρ−ρ₀)g) Reynolds number：Re = vdρ₀/η Re > 0.2 → 亂流 → 不適用 Stokes' law 臨界半徑（critical radius）： 布朗運動隨機位移 = 沉降向下位移 時的半徑 影響因素：黏度、重力、溫度（與分配係數無關）
黏度（Viscosity）
Einstein viscosity equation（球形粒子）： η = η₀(1 + 2.5φ) Relative viscosity = η/η₀ Specific viscosity = (η−η₀)/η₀ Reduced viscosity = specific viscosity / c → 理想值 2.5 Intrinsic viscosity = lim(c→0) reduced viscosity（極限黏度） 形狀影響： 球形 → 較低黏度 線形 → 較高黏度（若形成連續網狀凝集物 → 可觀察到 yield stress） 媒液親合性： 親溶媒（高親和力）→ 媒合→ 黏度較高 厭溶媒（低親和力）→ 傾向球形 → 黏度較低 應用：血漿替代劑（dextran、hydroxyethyl starch、gelatin）

🔋 膠體的電性 ▶
膠體表面帶電與電性雙層
  • 帶電原因：① 選擇性吸附溶液中特定離子（電位決定離子）；② 表面基團（如 −COOH）離子化
  • 緊密結合層（a-a' 至 b-b'）：緊密結合的溶劑分子及抗衡離子（counter ions / gegenions）
  • 擴散層（b-b' 至 c-c'，可移動層）
電位定義大小
Nernst potential（E，電熱力學電位）實際表面（a-a'）與電中性區之電位差最大
Zeta potential（ζ）緊密結合層表面（b-b'，滑動面）與電中性區之電位差中間（乙 > 甲）
Zeta potential 的重要性：
ζ↑ → 粒子間排斥力↑ → 安定（去凝絮）
ζ↓（小於引力）→ 粒子聚集（凝絮）
ζ 太高 → 動能過大，相撞也可能沉澱
電泳（Electrophoresis）
帶電粒子在外加電位差下，往相反電荷電極移動（可用超顯微鏡觀察） 決定移動速率之電位 = Zeta potential ζ = (v/E) × (4πη/ε) × (9×10⁴) [ζ in volts] v/E = mobility（移動性） 20°C 水性膠體系統：ζ ≈ 141(v/E)
AgI 膠體帶電示例
  • KI 加入 AgNO₃（Ag⁺ 過量）→ AgI 粒子吸附 Ag⁺ → 帶正電膠體
  • AgNO₃ 加入 NaI（I⁻ 過量）→ AgI 粒子吸附 I⁻ → 帶負電膠體

🛡️ 安定性：影響親溶媒膠體之因素 ▶
1. 溫度 — 相分離
  • 改變溫度 → 分散相溶解限度低於溶膠濃度 → 聚合物沉澱析出 → 凝膠化（gelation）
  • 沉澱之大分子彼此在接觸點相吸引 → 骨架狀聚合物鏈固化，甚至呈現結晶
  • 反方向改變溫度 → 凝膠溶化成 sol，各鏈重新媒合
例：Plastibase®
・成分：5% polyethylene + 95% mineral oil
・>90°C：polyethylene 溶於 mineral oil → 液狀
・<90°C：polyethylene 沉澱析出 → 凝膠（混纏之聚合物鏈形成網狀架構）
・口內膏（Orabase）= Plastibase + sodium CMC + pectin + gelatin
2. 非溶媒性液體 — 聚合物沉澱
  • 加入可與溶媒混合但不能溶解聚合物之液體 → 溶解度↓ → 沉澱/凝膠化
  • ex：乙醇於聚電解質水溶液中；加水稀釋可逆轉
3. 相反電荷之膠體 — Coacervation（共聚作用）
  • 正與負電荷之親水性膠體混合 → 巨分子分離為兩個液層
應用 — sulfamethoxazole microcapsule：
帶正電的 gelatin + 帶負電的 acacia → coacervation → 包覆 sulfamethoxazole 製備微膠囊
（H. Takenaka, Y. Kawashima, S.Y. Lin, J.P.S. 69, 513, 1980）
目的：sulfamethoxazole 味苦 → 微膠囊化 → taste masking（遮味）
4. 鹽類 — 鹽析（Salting out）
  • 高度水合性鹽類溶解後緊繫住大量水 → 供聚合物溶解之水減少 → 沉澱/凝膠化
  • 鹽析能力 ∝ 離子水合程度（Hofmeister / Lyotropic series）
陽離子鹽析能力：Li⁺ > Na⁺ > K⁺ > NH₄⁺ > Rb⁺ > Cs⁺ Mg²⁺ > Ca²⁺ > Sr²⁺ > Ba²⁺ 陰離子鹽析能力： F⁻ > Citrate³⁻ > HPO₄²⁻ > tartrate²⁻ > SO₄²⁻ > acetate⁻ > Cl⁻ > NO₃⁻ > ClO₃⁻ > Br⁻ > ClO₄⁻ > I⁻ > SCN⁻
親溶媒膠體安定化方法
  • 親溶媒性膠體本身為穩定系統，不像厭溶媒膠體需要特別幫助安定
  • 可藉下列方式更加安定：
    ① 減少外界環境造成之溶解度變化
    ② 增加連續相黏度 → 阻止布朗運動碰撞造成凝集（Stokes law：η↑ → v↓）

⚠️ 安定性：影響厭溶媒膠體之因素 ▶
影響因素
  • 1. 溫度、非溶媒性液體、鹽類：同親溶媒膠體，但厭溶媒膠體熱力學不安定，僅由表面電荷安定，因此更敏感
  • 2. 電荷（最重要因素）：粒子表面電荷 → 彼此排斥 → 安定；但 Zeta potential 太高 → 動能太大，相撞也可能沉澱
  • 加入相反電荷鹽類 → Zeta potential↓ → 凝集
Schulze-Hardy Rule / DLVO 理論
凝集能力隨對等離子（counter ion）價數增加而急劇增加 MCC（Minimum Coagulation Concentration）比例： 一價 : 二價 : 三價 = 1/1⁶ : 1/2⁶ : 1/3⁶ = 100 : 1.6 : 0.14 帶負電 gold sol 之 MCC： 一價（Na⁺, K⁺ 等）：avg 24 mmol/L（ex: NaCl, ½Na₂SO₄, KNO₃） 二價（Ca²⁺, Ba²⁺, Mg²⁺）：avg 0.38 mmol/L（ex: CaCl₂, BaCl₂, MgSO₄） 三價（Al³⁺, Ce³⁺, Cr³⁺）：avg 0.0325 mmol/L（ex: ½Al₂(SO₄)₃, Ce(NO₃)₃） 實測比 = 24 : 0.38 : 0.0325 ≈ 100 : 1.56 : 0.13 同價數離子：水合程度越低 → 越靠近膠體表面 → 凝集能力越強 ex: Cs⁺ 水合殼較小，比 Li⁺ 更靠近表面 → Cs⁺ 凝集能力 > Li⁺ （Li⁺ 引起凝集所需濃度 Ccv 最大） 特殊：AgNO₃ 之 Ag⁺ 可靠近 AgI 膠體粒子表面，同時降低 Nernst potential 與 Zeta potential → 凝集效果大

⚖️ 膠體粒子分子量測定 ▶
單分散系 vs 多分散系
  • 單分散系（Monodisperse）：粒子大小相同（天然/純蛋白質、簡單有機分子、多數合成藥品）；各種測重量方法結果相同
  • 多分散系（Polydisperse）：粒子大小不一（研細法或沉澱法製成之膠體懸液，或聚合物鏈形成過程）；分子大小及分子量不能只用一個數字代表
Mn vs Mw
數目平均分子量 Mn = ΣNᵢMᵢ / ΣNᵢ → 由滲透壓、蒸汽壓、凝固點測得 重量平均分子量 Mw = ΣWᵢMᵢ / ΣWᵢ = ΣNᵢMᵢ² / ΣNᵢMᵢ → 由光散射、超速離心法測得 單分散系：Mw = Mn 多分散系：Mw > Mn Polydispersity index = Mw/Mn

方法測得類型適用
