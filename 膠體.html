🔬 膠體系統類型 ▶
依分散相與分散媒親和性分類
類型特性例子電解質影響
親溶媒性膠體（Lyophilic）分散相與分散媒有吸引力，產生媒合（solvation）；熱力學穩定系統acacia、gelatin、insulin、albumin、starch、bentonite、povidone 分散於水；polystyrene 溶於苯高濃度電解質 → 鹽析
厭溶媒性膠體（Lyophobic）分散相對分散媒吸引力很小，粒子外圍無溶劑包覆；熱力學不穩定，需靠電荷安定gum rubber、cholesterol、polystyrene 於水；acacia、gelatin 於非極性溶媒極少量電解質就不穩定
結合膠體（Association colloid）亦稱兩性膠體（amphiphilic），兼具 lyophilic 與 lyophobic；由≥50 個 surfactant 單體凝集成 micelle（直徑約 50 Å）；肉眼下澄清，屬單相系界面活性劑水溶液超過 CMC 時高濃度電解質 → 鹽析
親溶媒性膠體細分
  • True solutions：水溶性高分子（acacia、povidone）
  • Gelled solutions / gels / jellies：高濃度或降溫使溶解度降低而形成（gelatin 冷卻；MC 加熱）
  • Particulate dispersions：不形成分子溶液，維持小而分散的粒子（bentonite、microcrystalline cellulose）
Micelle（微膠粒）與 CMC
CMC（Critical Micelle Concentration，臨界微膠粒濃度）： 濃度 < CMC → surfactant 以單體存在（< 膠體大小） 濃度 ≥ CMC → 自然凝集形成 micelle（結合膠體） 光散射測 micelle 分子量： H(c−cCMC)/(τ−τCMC) = 1/M + 2B(c−cCMC) 截距 → 分子量 M；斜率 B： B = 0：非離子/兩性 micelle（無交互作用） B > 0：離子性 micelle（電荷排斥） B < 0：多分散系統

💡 膠體的光學性質 ▶
Faraday-Tyndall Effect（法拉第-丁達爾效應）
  • 一束強光通過膠體溶液 → 光被膠體粒子散射 → 產生可見光錐
  • 粒子大小 > 入射光波長 → 光反射；粒子大小 < 入射光波長 → 光散射
  • 可見光波長：400–700 nm
  • 真溶液：太小，散射強度弱；粗分散系：太大，只反射
光散射測分子量
Hc/τ = 1/M + 2Bc τ：渾濁度（cm⁻¹）；c：溶質濃度（g/cm³） M：平均分子量；B：交互作用常數 H = 32π³n²(dn/dc)²/(2λ⁴N) 以 Hc/τ（Y軸）對 c（X軸）作圖： 截距 = 1/M → 求分子量 斜率 = 2B → 看交互作用

⚡ 膠體的動力學性質 ▶
布朗運動（Brownian Motion）
  • Robert Brown 提出：<5 μm 之粒子在顯微鏡下可見不規則運動
  • 液體分子不斷隨機碰撞膠體粒子 → 連續不規則運動
  • 影響因素：與濃度無關；溫度↑ → 位移↑；粒徑↑ → 位移↓；黏度↑ → 位移↓
擴散（Diffusion）
Fick's First Law： J = dM/(S·dt) = −D·(dC/dx) 擴散係數 D = kT/(6πrη) = RT/(6πrηN) 由 D 計算球形分子量： D = RT/(6πηN) · ∛(3/(4πN) · 1/M · 1/v) 擴散速率 ∝ 溫度↑、粒子↓ 擴散速率 ∝ 1/黏度、1/粒子大小
滲透壓（Osmotic Pressure）
理想稀薄溶液：π = cRT = (cg/M)RT → π/cg = RT/M 聚合物（考慮交互作用）： π/cg = RT/M + RTBcg 截距（RT/M）→ 求 M 斜率（RTB）→ 看溶質-溶劑交互作用 B > 0：溶劑-溶質引力 > 溶質間引力（媒合良好） B = 0：理想溶液 B < 0：溶質間引力 > 溶劑-溶質（會沉澱）
注意：滲透壓法只適用於親溶媒系統（大分子溶液或 surfactant micelle）；厭溶媒系統之滲透壓不易準確測量。
沉降作用（Sedimentation）
Stokes' Law（假設球形粒子、層流、稀薄分散系）： v = 2r²(ρ−ρ₀)g / 9η = d²(ρ−ρ₀)g / 18η r：半徑 ρ：粒子密度 ρ₀：液體密度 g：重力加速度 η：液體黏滯係數 臨界半徑（critical radius）： 布朗運動位移 = 沉降向下位移 時的半徑 影響因素：溫度、重力、黏度（與分配係數無關） Reynolds number Re = vdρ₀/η Re > 0.2 → 亂流 → 不適用 Stokes' law
黏度（Viscosity）
Einstein viscosity equation（球形膠體）： η = η₀(1 + 2.5φ) η/η₀ = relative viscosity (η−η₀)/η₀ = specific viscosity reduced viscosity = specific viscosity/c → 理想值 2.5 intrinsic viscosity [η] = lim(c→0) reduced viscosity 形狀影響： 球形 → 較低黏度 線形（rod/fiber）→ 較高黏度 應用：血漿替代劑（dextran、hydroxyethyl starch、gelatin）

⚡ 膠體的電性 ▶
電性雙層（Electric Double Layer）
  • 膠體粒子帶電原因：① 選擇性吸附溶液中特定離子；② 表面基團（如 −COOH）離子化
  • 緊密結合層（Stern layer）：緊密結合的溶劑分子與反離子（counter ions / gegenions）
  • 擴散層（Diffuse/Mobile layer）：可移動層
電位名稱定義大小關係
Nernst potential（E，電熱力學電位）實際表面與電中性區之電位差最大
Zeta potential（ζ）緊密結合層表面（滑動面）與電中性區之電位差中間（E > ζ）
Zeta potential 的重要性：
ζ 高 → 粒子間排斥力強 → 系統安定（去凝絮）
ζ 低（<引力）→ 粒子凝集（凝絮）
但 ζ 太高 → 動能過大，相撞也可能沉澱
電泳（Electrophoresis）
帶電粒子在外加電位差下，往相反電荷電極移動 ζ = (v/E) × (4πη/ε) × (9×10⁴) [ζ in volts] v/E = mobility（移動性） 20°C 水性系統：ζ ≈ 141(v/E)
AgI 膠體帶電示例
  • KI 加入 AgNO₃（Ag⁺ 過量）→ AgI 粒子吸附 Ag⁺ → 帶正電膠體
  • AgNO₃ 加入 NaI（I⁻ 過量）→ AgI 粒子吸附 I⁻ → 帶負電膠體

🛡️ 膠體系統安定性：親溶媒性膠體 ▶
影響親溶媒膠體安定性之因素
  • 1. 溫度：改變溫度 → 聚合物相分離 → 凝膠化（gelation）或溶化（sol）
  • 例：Plastibase®（5% polyethylene + 95% mineral oil）
    ・>90°C：polyethylene 溶於 mineral oil → 液狀
    ・<90°C：polyethylene 沉澱析出 → 凝膠
    ・口內膏（Orabase）= Plastibase + sodium CMC + pectin + gelatin
  • 2. 非溶媒性液體：加入可與溶媒混合但不溶聚合物之液體 → 降低溶解度 → 沉澱/凝膠化（ex：乙醇於聚電解質水溶液）；加水可逆轉
  • 3. 相反電荷之膠體（Coacervation，共聚作用）：正與負電荷親水性膠體混合 → 巨分子分離為兩液層
Coacervation 應用 — sulfamethoxazole microcapsule：
帶正電的 gelatin + 帶負電的 acacia → coacervation → 包覆 sulfamethoxazole 製備微膠囊
（H. Takenaka, Y. Kawashima, S.Y. Lin, J.P.S. 69, 513, 1980）

目的：sulfamethoxazole 味苦 → 以 gelatin/acacia coacervate 包覆 → taste masking（遮味）
  • 4. 鹽類（鹽析）：高度水合性鹽類溶解後緊繫住水 → 供聚合物溶解之水減少 → 沉澱/凝膠化
Hofmeister / Lyotropic Series（鹽析能力）
陽離子（鹽析能力）：Li⁺ > Na⁺ > K⁺ > NH₄⁺ > Rb⁺ > Cs⁺ Mg²⁺ > Ca²⁺ > Sr²⁺ > Ba²⁺ 陰離子（鹽析能力）： F⁻ > Citrate³⁻ > HPO₄²⁻ > tartrate²⁻ > SO₄²⁻ > acetate⁻ > Cl⁻ > NO₃⁻ > ClO₃⁻ > Br⁻ > ClO₄⁻ > I⁻ > SCN⁻ 水合程度越高 → 鹽析能力越強
親溶媒膠體安定化方法
  • 減少外界環境造成之溶解度變化
  • 增加連續相黏度 → 阻止布朗運動碰撞造成凝集（Stokes' law：η↑ → v↓）

⚠️ 膠體系統安定性：厭溶媒性膠體 ▶
影響厭溶媒膠體安定性之因素
  • 1. 溫度、非溶媒液體、鹽類：同親溶媒膠體，但更敏感（極少量電解質就不穩）
  • 2. 電荷（最重要）：粒子表面電荷 → 彼此排斥 → 安定；Zeta potential 越高越安定（但太高反而因動能大而相撞沉澱）
  • 加入相反電荷鹽類 → Zeta potential↓ → 凝集
Schulze-Hardy Rule（DLVO 理論）
凝集能力隨對等離子（counter ion）價數增加而急劇增加 最小凝集濃度（MCC）比例： 一價 : 二價 : 三價 = 1/1⁶ : 1/2⁶ : 1/3⁶ = 100 : 1.6 : 0.14 例：帶負電金膠溶體（gold sol）之 MCC： 一價陽離子（Na⁺, K⁺）：avg 24 mmol/L 二價陽離子（Ca²⁺, Ba²⁺, Mg²⁺）：avg 0.38 mmol/L 三價陽離子（Al³⁺, Ce³⁺, Cr³⁺）：avg 0.0325 mmol/L 同價數離子：水合程度越低 → 越靠近膠體表面 → 凝集能力越強 e.g. Cs⁺ 水合殼較小 → 比 Li⁺ 更靠近表面 → Cs⁺ 凝集能力 > Li⁺

⚖️ 膠體粒子分子量測定 ▶
單分散系 vs 多分散系
  • 單分散系（Monodisperse）：所有粒子大小相同（天然/純蛋白質、簡單有機分子）
  • 多分散系（Polydisperse）：粒子大小不一（研細或沉澱法製備之膠體懸液、聚合物）
數目平均分子量 vs 重量平均分子量
數目平均分子量 Mn = ΣNᵢMᵢ / ΣNᵢ → 由滲透壓、蒸汽壓、凝固點測得 重量平均分子量 Mw = ΣWᵢMᵢ / ΣWᵢ = ΣNᵢMᵢ² / ΣNᵢMᵢ → 由光散射、超速離心法測得 多分散系：Mw > Mn 單分散系：Mw = Mn Polydispersity index = Mw/Mn
各測量方法對應的分子量
方法測得分子量類型適用
滲透壓法Mn（數目平均）親溶媒系統
光散射法Mw（重量平均）膠體、高分子
超速離心沉降法Mw（重量平均）蛋白質、膠體
黏度法黏均分子量（近似 Mw）聚合物
過篩法❌ 無法測分子量—
掃描式電子顯微鏡（SEM）❌ 無法測分子量（測粒徑形態）—
