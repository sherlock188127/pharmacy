📐 膠體粒子大小與比表面積 ▶
比表面積公式（Specific Surface Area, Aₛₚ）
【正方體，邊長 ι，密度 d】 Aₛₚ = A/V = 6/ι Aₛₚ = A/M = 6/(ι·d) 【球形，直徑 D，密度 d】 Aₛₚ = A/V = 6/D Aₛₚ = A/M = 6/(D·d) ➜ 粒子越小 → 比表面積越大 ➜ 倍增關係：邊長 L₁ → L₂，Aₛₚ 增加 L₁/L₂ 倍
粒徑影響各種性質
  • 顏色：細→淺（HgO、Fe₂O₃：細→黃，粗→紅）
  • 氣味：細→濃
  • 溶解速率：細→快
  • 化學穩定性：細→不安定（接觸面積大）
  • 催化效果：鉑黑（膠態鉑）Aₛₚ 大，催化佳
  • 藥物吸收：細→吸收快
  • 局部刺激性：細→刺激大（AgNO₃→colloidal silver protein）
  • 透析：火棉膠/玻璃紙膜，依粒子大小分離（超濾、血液透析）

親溶媒性膠體製備
  • 簡單分散法：將分散相加入分散媒，濕潤後輕攪至分散
  • 化學反應法：鎂乳：MgSO₄ + 2NaOH → Mg(OH)₂↓；氫氧化鋁膠漿：Al₂(SO₄)₃ + Na₂CO₃ + H₂O → Al(OH)₃↓
厭溶媒性膠體製備（不能自然形成）
  • 分散法：超音波、膠體磨（colloidal mill）、電極分散法
  • 凝結法：降低溶解度（硫磺酒精液倒入水中）；還原法（金/銀鹽+甲醛）；氧化法（H₂S→硫原子）；水解法（AlCl₃+沸水→Al(OH)₃）
CMC（臨界微膠粒濃度）
  • 超過 CMC 才形成微膠粒；單體濃度超過 CMC 後不再增加
  • 交互作用常數 B：非離子性≈0；離子性 B>0；B<0 表多分散性

💡 膠體的光學性質 ▶
Faraday-Tyndall 效應
強光通過膠體溶液 → 光被膠體粒子散射 → 產生可見光錐
粒子大小 vs 光：
粒子 > 入射光波長（400-700nm）→ 光反射（粗分散系）
粒子 < 入射光波長 → 光散射（膠體）✓
真溶液：太小 → 散射強度弱
光散射與分子量（Debye 方程式）
Hc/τ = 1/M + 2Bc H��系統常數（與波長 λ 有關） c：溶質濃度 τ：渾濁度 M：重量平均分子量 B：交互作用常數 以 Hc/τ 對 c 作圖：截距 = 1/M → 求 Mw；斜率 = 2B → 看交互作用 B > 0：離子性微膠粒（粒子間排斥） B = 0：非離子性/兩性微膠粒（典型） B < 0：多分散性系統
微膠粒分子量（利用光散射）
總濃度 c = c_monomer + c_micelle 單體超過 CMC 後固定 = CMC ∴ c_micelle = c − CMC τ_micelle = τ_total − τ_monomer H(c−CMC)/τ_micelle = 1/M_micelle + 2B(c−CMC)
⚛️ 膠體的動力學性質 ▶
布朗運動 (Brownian Motion)
  • 粒子 <5 μm 在顯微鏡下可見不規則運動（液體分子隨機撞擊）
  • 位移公式：x² = 2Dt（D = 擴散係數）
  • 位移與溫度↑成正比；與粒徑↑、黏度↑成反比；與濃度無關
  • 觀察皂土扁平粒子布朗運動 → 利用 Tyndall 效應

擴散 (Diffusion) — Fick's First Law
J = dM/(S·dt) = −D·(dC/dx) D（擴散係數）= kT/(6πηr) = RT/(6πηrN) 球形粒子分子量： M = (4/3)πr³·ρ·N → r = [3M/(4πρN)]^(1/3) 擴散速率：粒子↓ → D↑；溫度↑ → D↑；黏度↑ → D↓
滲透壓 (Osmotic Pressure)
理想稀薄溶液：π = cRT = (cg/M)RT 聚合物（非理想）：π/cg = RT/M + RTBcg 截距 RT/M → 求 Mₙ（數目平均分子量） 斜率 RTB → 看溶質-溶劑交互作用 B > 0：溶劑-溶質引力大（媒合佳） B < 0：溶質間引力大 → 可能沉澱 B = 0：理想溶液
滲透壓只適用於親溶媒系統；厭溶媒系統難測。

沉降作用 (Sedimentation) — Stokes' Law
沉降速率：v = 2r²(ρ−ρ₀)g / 9η = d²(ρ−ρ₀)g / 18η ρ > ρ₀ → 沉降；ρ < ρ₀ → 上浮 Reynolds number 判斷層流： Rₑ = vdρ₀/η ≤ 0.2 → 適用 Stokes' law → 臨界直徑：d²= 18×0.2×η / [(ρ−ρ₀)ρ₀g] 儀器：Andreasen pipette（需知粒子密度才能計算粒徑）
v 正比：r²、(ρ−ρ₀)、g；v 反比：η（黏度↑ → 沉降↓ → 更穩定）

黏度 (Viscosity)
η/η₀ = relative viscosity（相對黏度） ηsp = (η−η₀)/η₀ = specific viscosity（比黏度） ηred = ηsp/c = reduced viscosity（比濃黏度） [η] = lim(c→0) ηred = intrinsic viscosity（極限黏度） Einstein 方程式（理想球形）：reduced viscosity = 2.5
  • 球形粒子 → 較低黏度；線形粒子 → 較高黏度
  • 親溶媒性膠體（媒合）→ 黏度高；厭溶媒性 → 黏度低
  • 血漿替代品：dextran、hydroxyethyl starch、gelatin

⚡ 膠體的電性 ▶
電位與電性雙層
固體表面(a-a') → 緊密結合層(b-b') → 擴散層(c-c') → 電中性區(d-d') Nernst potential (E)：固體表面 與 電中性區 之電位差（最大） Zeta potential (ζ) ：緊密結合層外 與 電中性區 之電位差 大小關係：E（表面電位）> ζ（Zeta 電位）> 擴散層外界限電位 ζ 大 → 粒子間排斥 → 穩定（去凝絮） ζ 小 → 引力 > 斥力 → 凝集（凝絮）
AgI 膠體帶電範例（電位決定離子）
  • KI 加入 AgNO₃（Ag⁺ 過量）→ Ag⁺ 吸附於表面 → 帶正電
  • AgNO₃ 加入 NaI（I⁻ 過量）→ I⁻ 吸附於表面 → 帶負電
電泳 (Electrophoresis)
ζ（statvolts）= (v/E) × (4πη/ε) 水溶液 20℃：ζ（V）≈ 141 × (v/E) v/E = mobility（移動性）

🛡️ 膠體安定性：親溶媒性膠體 ▶
影響因素
  • 溫度：溶解度↓ → 凝膠化（gelation）；反向升溫可恢復（Plastibase® = 5%聚乙烯+95%礦油，<90℃凝膠）
  • 非溶媒性液體：加入可混溶但不溶解聚合物的液體 → 溶解度↓ → 凝膠化（加水可逆轉）
  • 相反電荷膠體：正+負電荷親水膠體 → 共聚（coacervation）（gelatin+acacia → 製備磺胺甲噁唑微膠囊）
  • 鹽類（鹽析）：高濃度電解質水合搶水 → 聚合物沉澱
Lyotropic（Hofmeister）Series — 鹽析能力
水合程度越大 → 鹽析能力越強（所需濃度越小） 陽離子：Li⁺ > Na⁺ > K⁺ > NH₄⁺ > Rb⁺ > Cs⁺ Mg²⁺ > Ca²⁺ > Sr²⁺ > Ba²⁺ 陰離子：F⁻ > Citrate³⁻ > HPO₄²⁻ > tartrate²⁻ > SO₄²⁻ > acetate⁻ > Cl⁻ > NO₃⁻ > Br⁻ > ClO₄⁻ > I⁻ > SCN⁻ 親溶媒膠體安定化方式： 1. 減少外界環境造成之溶解度變化 2. 增加連續相黏度（阻止布朗運動碰撞造成凝集）

⚠️ 膠體安定性：厭溶媒性膠體 ▶
電荷與安定性
  • 厭溶媒膠體靠表面電荷（Zeta potential）維持安定
  • 加入相反電荷電解質 → ζ↓ → 凝集
  • Schulze-Hardy rule：凝集能力隨對等離子價數增加而急劇增加
D-L-V-O 理論（最小凝結濃度 MCC）
MCC ∝ 1/z⁶（z = 對等離子價數） 理論比：一價：二價：三價 = 1/1⁶：1/2⁶：1/3⁶ = 100：1.56：0.13 帶負電金膠溶體實測： 一價（NaCl、KNO₃…） MCC ≈ 24 mmol/L 二價（CaCl₂、BaCl₂…）MCC ≈ 0.38 mmol/L 三價（Al₂(SO₄)₃…） MCC ≈ 0.0325 mmol/L 同價數→水合程度越大→越難靠近表面→凝集能力越弱→MCC越大 陽離子：Li⁺ > Na⁺ > K⁺ > Cs⁺（Li⁺ 水合最大，MCC最大，凝集最弱） 二價：Mg²⁺ > Ca²⁺ > Sr²⁺ > Ba²⁺

🥇 厭溶媒膠體安定化 & 保護性膠體（金數） ▶
三種安定化方式
  • Charge stabilization：使粒子帶電荷（加鹽類或離子性界面活性劑）
  • Steric stabilization：加非離子性界面活性劑（碳氫鏈吸附粒子表面，PEO 鏈與水形成氫鍵）
  • Protective colloidal action：親水性膠體包覆厭水性粒子
保護性膠體作用 vs 敏感化（Sensitization）
保護性膠體作用敏感化 (Sensitization)

⚖️ 膠體分子量測定方法 ▶
數目平均 Mₙ vs 重量平均 Mw
Mₙ（數目平均）= ΣNᵢMᵢ / ΣNᵢ 每個分子等權重；由滲透壓、蒸汽壓、凝固點測得 Mw（重量平均）= ΣNᵢMᵢ² / ΣNᵢMᵢ 以本身重量為權重；由光散射、超速離心測得 Mw ≥ Mₙ（多分散系）；Mw = Mₙ（單分散系） Polydispersity = Mw/Mₙ
各方法對應分子量類型
方法測得分子量
滲透壓、蒸汽壓、凝固點下降數目平均 Mₙ
光散射（Tyndall/turbidity）重量平均 Mw
超速離心（沉降速率）重量平均 Mw
黏度法黏度平均 Mη（介於 Mₙ 與 Mw 之間）
掃描式電子顯微鏡（SEM）❌ 測粒徑形狀，無法直接測分子量
過篩法❌ 粒徑分級，無法測分子量
