心血管四藥重點整理

Digoxin、Lidocaine、Procainamide、Quinidine 各自的機轉、藥動參數、治療／中毒濃度、疾病狀態影響與藥物交互作用（交互作用標明主詞與方向）。點上方藥名切換，點各區塊標題展開／收合。

四藥共通規律 · 一眼抓重點
考前快速複習
★三條黃金規律▶
  • amiodarone 一律往上抬：使 digoxin ↑2–3 倍、procainamide ↑57%、quinidine 也升高。看到 amiodarone 併用抗心律不整藥，先想「濃度上升、注意毒性」。
  • rifampin 一律往下：對 digoxin（誘導 PGP）、quinidine（誘導 CYP3A）都使其↓。歸類題裡常是「方向與其他不同」的那個答案。
  • cimetidine 雙重抬高：使 lidocaine↑（抑制酶）、procainamide↑（競爭腎小管分泌）—— 同一個藥、兩種機轉，別搞混。

★最常考的陷阱▶
  • verapamil 對 digoxin：機轉是「抑制小腸 P-glycoprotein」，與代謝（CYP）無關。
  • 巨環類 vs neomycin：同屬抗生素，erythromycin/clarithromycin 使 digoxin↑、neomycin 使其↓ —— 方向相反。
  • codeine + quinidine：一般 CYP2D6 抑制使藥濃度↑，但 codeine 是前驅藥需活化，被抑制反而止痛失效。
  • 低血鉀（非高血鉀）增加 digoxin 毒性敏感度。
  • quinidine + digoxin：使 digoxin↑30–50%，超經典。

Digoxin

強心苷 cardiac glycoside
CHF 第二線 · AF 控制心室率
◆一句話重點▶
  • 臨床最主要的強心苷；CHF 用其正性肌力（inotropic）、AF 用其變時性（chronotropic）控制心室率。
  • 兩種適應症皆非第一線，多為第二線或後線；AF 通常與 β-blocker 或 CCB 併用，單獨使用無法恢復竇性心律。
  • 治療範圍狹窄、Vd 大、主要經腎排除 —— TDM 的經典藥。
◆藥動參數▶
排除
腎排除 ~75%（腎絲球過濾＋腎小管主動分泌）；肝代謝/膽汁 ~25%（PGP 介導、腸肝循環）
生體可用率
錠劑 F=0.7、溶液 F=0.8；不建議 IM（吸收不穩、疼痛）；IV 須輸注 5–10 分鐘
蛋白結合
約 25%（不高）
Vd
很大、會蓄積組織；肥胖者以 IBW 計算（不分布到脂肪）
半衰期
正常約 36 hr；腎衰竭延長至約 120 hr；甲狀腺亢進較短
模型
二室模式，分布相 8–12 hr，須過分布相後抽血
清除率
與 CrCl 成正比。無中重度 HF：Cl=1.303(CrCl)+40；有中重度 HF（NYHA III/IV）：Cl=1.303(CrCl)+20
◆治療 / 中毒濃度▶
CHF（inotropic）

AF（chronotropic）
0.8–1.5 ng/mL（最高可達 2 ng/mL）
毒性風險
> 2 ng/mL 大幅上升；> 2.5 ng/mL 約半數出現症狀
  • GI：厭食、噁心、嘔吐、腹瀉、腹痛。CNS：頭痛、疲倦、失眠、混亂、眩暈、視覺障礙（黃綠視）。心臟：AV block、心搏過緩、心室心律不整。
  • 危及生命毒性 → digoxin immune FAB（DigiFab）。
◆電解質（重要）▶
  • 加重毒性者：低血鉀、低血鎂、高血鈣。
  • 須監測血鉀：使用排鉀利尿劑者、使用 ACEI / ARB 者（鉀滯留風險）。低血鉀會誘發毒性，必要時補鉀。
  • 嚴重心臟病（CAD、MI）患者對 digoxin 較敏感。
◆藥物交互作用（機轉＋原理＋考點）▶

Digoxin 約 75% 經腎排除、其分泌與腸道吸收皆受 P-glycoprotein（PGP）調控，且治療範圍狹窄。因此交互作用集中在三個機轉：① 抑制/誘導 PGP → 改變分泌與吸收；② 抑制腎/組織清除；③ 改變腸道吸收。

① 抑制 PGP 或清除 → 使 digoxin 濃度上升（中毒風險↑）

藥物幅度為什麼上升（原理）
amiodarone↑ 2–3 倍抑制 PGP 並降低腎/非腎清除；半衰期長故起效慢、退得也慢
verapamil↑ 最多 70%CCB 中抑制 digoxin 清除最強者
quinidine↑ 30–70%抑制 PGP、降低腎清除與置換組織結合（增加 3~7 成）
propafenone↑ 30–60%抑制 PGP，呈劑量依賴性
cyclosporine↑ 50%抑制 PGP
diltiazem、bepridil↑ 約 30%抑制 digoxin 清除（CCB，弱於 verapamil）
巨環類抗生素
（erythromycin、clarithromycin）		↑ 約 30%抑制 PGP，並殺死腸道把 digoxin 代謝掉的菌叢，使吸收增加（部分病人）

② 誘導 PGP 或降低吸收 → 使 digoxin 濃度下降（療效↓）

藥物方向為什麼下降（原理）
rifampin↓誘導 PGP，增加 digoxin 分泌排除
sulfasalazine、neomycin↓降低 digoxin 的生體可用率（吸收減少）
cholestyramine↓在腸道吸附 digoxin，須間隔 8 小時服用
含鋁制酸劑、kaolin-pectin↓在腸道結合 digoxin，須間隔 2 小時服用
metoclopramide、cisapride↓加速腸道通過，縮短吸收時間使生體可用率下降

③ 例外：加速腸道通過卻使吸收上升

propantheline↑減慢腸道蠕動，延長吸收時間 → 使 digoxin 生體可用率上升
★ 考點整理
  • 「方向與其他不同」題：一堆使 digoxin↑ 的藥裡，rifampin 是唯一使其↓（誘導 PGP）— 最常拿來當答案。
  • verapamil 機轉題：答案是「抑制小腸 P-glycoprotein」，與代謝（CYP）無關，digoxin 也不靠 CYP 代謝。
  • 巨環類陷阱：erythromycin、clarithromycin 使 digoxin↑（中毒↑）；但 neomycin 相反（降低生體可用率使↓）— 同屬抗生素卻方向相反。
  • amiodarone：↑ 2–3 倍且起效慢（半衰期長），是幅度最大者。
  • 低血鉀（非高血鉀）會增加 digoxin 毒性敏感度，常與上述藥物一起出現在「使 Css 升到中毒」的複選題。

Lidocaine

Type IB 抗心律不整藥 ＋ 局部麻醉劑
VT 用藥 · 肝代謝為主
◆一句話重點▶
  • Type IB，用於心室頻脈（VT），為 procainamide、amiodarone、sotalol 的替代藥；亦為局部麻醉劑。
  • 機轉：抑制鈉離子內流，降低傳導速度與不反應期。
  • 與 digoxin 最大差別：分布快、排除較慢；>95% 肝代謝，腎衰竭重點在代謝物累積。
◆藥動參數▶
模型
二室模式：分布快、排除慢
半衰期
正常 1–1.5 hr；肝衰竭 5+ hr
代謝
>95% 肝臟 CYP3A；代謝物 MEGX、GX（經腎排除）
◆治療 / 毒性濃度▶
治療範圍
1.5–5 μg/mL
> 3 μg/mL
嗜睡、頭暈、感覺異常
> 6 μg/mL
肌肉抽搐、癲癇、昏迷、心血管衰竭
◆疾病狀態影響▶
狀態影響調整
肝硬化清除率↓、半衰期↑減量，密切監測
心衰竭清除率↓、Vd↓減量
心肌梗塞蛋白結合↑（AGP 上升）監測 AGP，調整劑量
腎衰竭代謝物 MEGX、GX 累積監測 CNS 毒性
◆藥物交互作用（機轉＋原理＋考點）▶

Lidocaine >95% 經肝臟 CYP 代謝，且為高肝抽提率（high extraction ratio）藥物，清除率高度依賴肝血流量（LBF）。因此交互作用兩條路：① 減少肝血流或抑制酶 → 清除↓；② 誘導酶 → 清除↑。

① 降低清除 → 使 lidocaine 濃度上升（毒性風險↑）

藥物對 lidocaine為什麼上升（原理）
β-blockers
（propranolol、metoprolol、nadolol）		濃度↑減少肝血流量（↓LBF），高抽提率藥清除隨之下降
cimetidine濃度↑抑制肝代謝酶，降低 lidocaine 清除

② 誘導酶 → 使 lidocaine 濃度下降（療效↓）

藥物對 lidocaine為什麼下降（原理）
phenytoin、phenobarbital濃度↓誘導肝代謝酶，加速 lidocaine 清除
★ 考點整理
  • 機轉分兩種別搞混：β-blocker 是「減肝血流」、cimetidine 是「抑制酶」，兩者結果都是 lidocaine↑，但原理不同。
  • 高抽提率（high E）藥對肝血流變化敏感，是 lidocaine 與 morphine 的共同特性（對照低抽提率的 phenytoin、warfarin、valproic acid）。
  • 誘導劑（phenytoin、phenobarbital）方向相反 → lidocaine↓，常當「方向不同」的選項。
◆給藥 & 調整▶
  • 負荷劑量 LD = Css × V；持續輸注 R = Css × Cl。
  • 負荷 1–1.5 mg/kg IV（2–5 分鐘緩慢給予，最大 50 mg/min）。
  • 輸注：正常 3–4 mg/min；肝病/心衰竭減半（1–2 mg/min）；小兒 20–50 μg/kg/min。
記　肝代謝為主 → 肝病/心衰竭減半；腎衰竭時盯代謝物 CNS 毒性（MEGX、GX 經腎排除）。

Procainamide

Type IA 抗心律不整藥
活性代謝物 NAPA（Type III）· 肝腎各半
◆一句話重點▶
  • Type IA，用於室上性與心室性心律不整（含 AF、VT）。
  • 機轉：抑制鈉離子內流、延長動作電位、降低傳導速度。
  • 關鍵：活性代謝物 NAPA 具 Type III 作用（Type I → III），腎衰竭時 NAPA 累積。

◆藥物交互作用（機轉＋原理＋考點）▶

Procainamide 約一半經腎排除（腎小管主動分泌），活性代謝物 NAPA 幾乎全經腎排除。因此會降低腎清除（尤其干擾腎小管分泌）的藥物，就會讓 procainamide 與 NAPA 一起堆積。

使 procainamide / NAPA 濃度上升（毒性風險↑）

藥物幅度為什麼上升（原理）
cimetidine濃度↑競爭腎小管主動分泌，降低 procainamide 與 NAPA 的腎清除
trimethoprim濃度↑同樣競爭腎小管分泌，使兩者腎清除下降
fluoroquinolones濃度↑降低腎清除，使 procainamide 與 NAPA 濃度上升
amiodarone↑ 約 57%使 procainamide 濃度上升約 57%
★ 考點整理
  • 核心機轉：cimetidine、trimethoprim、fluoroquinolones 都是降低腎清除（競爭腎小管分泌），使 procainamide 與 NAPA 同時上升。
  • 別忘了NAPA 也會一起堆積，它具 Type III 作用、幾乎全經腎排除 → 腎衰竭時最該監測毒性。
  • amiodarone 對多個抗心律不整藥都「往上抬」：digoxin（↑2–3 倍）、procainamide（↑57%）、quinidine 也類似 — 可一起記。
  • cimetidine 同時會抬高 lidocaine 與 procainamide（但機轉不同：lidocaine 是抑制酶、procainamide 是搶腎小管分泌）。
◆給藥 & 調整▶
  • IV 負荷 15 mg/kg（25–30 分鐘，最大 50 mg/min）；IV 輸注 2–4 mg/min。
  • 口服緩釋：正常 1000–1500 mg 每 6–12 hr；腎損傷 500–1000 mg 每 12–24 hr（減半、拉長）；小兒 15–50 mg/kg/day。
  • 肝/腎病輸注降至 1–2 mg/min。
記　腎衰竭最該擔心 NAPA 累積；amiodarone 使 procainamide 上升約 57%。

Quinidine

Type IA 抗心律不整藥
肝代謝為主 · 高蛋白結合 · cinchonism
◆一句話重點▶
  • Type IA，用於室上性與心室性心律不整，可將 AF 轉復為竇性心律。
  • 機轉：抑制鈉離子內流、降低傳導速度、延長動作電位。
  • 特徵：80% 肝代謝、高蛋白結合（80–90%）、強首渡代謝；會抑制 digoxin 清除使 digoxin↑。

◆藥物交互作用（機轉＋原理＋考點）▶

Quinidine 80% 經肝臟 CYP3A 代謝，本身又是 CYP2D6 抑制劑，且會抑制 P-glycoprotein。所以它有三種角色：① 被 CYP3A 抑制劑/誘導劑影響（受質）；② 抑制別藥的 CYP2D6 代謝（加害者）；③ 抑制 digoxin 清除。

① quinidine 是 CYP3A 受質 → 別藥改變它的濃度

藥物對 quinidine為什麼（原理）
CYP3A 抑制劑
（erythromycin、ketoconazole、verapamil）		quinidine↑抑制 CYP3A，減少 quinidine 代謝使其濃度上升
CYP3A 誘導劑
（phenytoin、phenobarbital、rifampin）		quinidine↓誘導 CYP3A，加速 quinidine 代謝使其濃度下降

② quinidine 是 CYP2D6 抑制劑 → 它使別藥濃度上升

受影響藥物方向為什麼（原理）
β-blockers、TCAs、opioids（如 codeine）他藥↑quinidine 抑制 CYP2D6，減少這些藥代謝使其濃度上升

※ 特例：codeine 需經 CYP2D6 活化成 morphine 才有止痛效果，被 quinidine 抑制後反而止痛效果下降。

③ quinidine 抑制 digoxin 清除

quinidine → digoxindigoxin↑ 30–50%抑制 PGP、降低 digoxin 腎清除並置換組織結合
★ 考點整理
  • 三種角色分清楚：對 CYP3A 是受質（被影響）、對 CYP2D6 是抑制劑（去影響別人）、對 digoxin 是抬高者。
  • quinidine + digoxin 是超經典考題：使 digoxin↑30–50%，與 amiodarone、verapamil 同列「使 digoxin 上升」的藥。
  • codeine 特例：一般 CYP2D6 抑制是讓藥濃度上升，但 codeine 是前驅藥需活化，被抑制反而失效（止痛變差）— 反向陷阱題。
  • rifampin 又出現了：對 quinidine 是誘導劑使其↓，對 digoxin 也是誘導 PGP 使其↓ — rifampin 一律往下。
◆給藥 & 調整▶
  • 口服 sulfate：200–400 mg 每 6–8 hr。
  • 口服 gluconate（緩釋）：正常 648 mg 每 8–12 hr；肝病 324–600 mg 每 12 hr；心衰竭減量 25–50%。
  • IV 負荷 500 mg，2 小時內。
記　sulfate 與 gluconate 兩鹽類劑量不同；腎影響小（20% 經腎），肝影響最大；別忘了它會抬高 digoxin。
