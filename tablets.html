💊 錠劑材料精華筆記 (Tablet Excipients)

1. 稀釋劑與填充劑 (Diluents / Fillers)

目的：使錠劑重量、體積增加，以利於打錠 [cite: 7]。

  • Lactose (乳糖)：溶解度高、壓錠性好 [cite: 8]。
  • Microcrystalline cellulose (MCC)：常用稀釋劑 [cite: 8]。
  • Calcium phosphate (磷酸二鈣)：常用稀釋劑 [cite: 8]。
  • Calcium sulfate (硫酸鈣)：固醇類或 Vit. 錠劑適用 [cite: 11]。
  • 咀嚼錠專用：甘露醇 (mannitol)、山梨醇 (sorbitol)、木醣醇 (xylitol)，具放熱清涼感 [cite: 13]。
  • ⚠️ 禁忌 Tetracycline：不可用鈣鹽類稀釋劑，會產生螯合作用 [cite: 10]。

2. 黏合劑 (Binders)

目的：濕潤藥粉促進黏著，增加粒徑與流動性，提升硬度 [cite: 22]。

💧 水性溶液 (Aqueous)
  • 澱粉糊 (Starch paste)：濃度 10-20% [cite: 26]。
  • 明膠溶液 (Gelatin solution)：10-20%，多用於口含錠，需溫熱使用 [cite: 38]。
  • Povidone (PVP)：非離子性水溶性膠體 [cite: 24]。
  • 蔗糖 (Sucrose)：常用黏合劑 [cite: 24]。
🧪 非水性溶液 (Non-aqueous / 對水敏感)
  • PVP / HPMC / HPC：可用酒精泡成造粒液，用於濕式造粒 [cite: 30, 36, 37]。
  • PVP：吸濕性高，少用於膜衣包覆 [cite: 36]。
📦 乾燥粉狀 (Dry Binders)
  • MCC / Acacia powder / PVP / Amylose / Colloidal clays：常用乾燥粉狀黏合劑 [cite: 1, 2]。

3. 崩散劑 (Disintegrants)

目的：克服錠片黏合強度，使藥物迅速融離 [cite: 16]。

  • 毛細作用 Crospovidone、MCC：藉由孔洞將水導入促進崩散 [cite: 19]。
  • 膨脹型 Sodium starch glycolate (2%)、Croscarmellose (5%)：遇水膨脹把錠劑脹破 [cite: 19]。
  • 其他材料：澱粉、MC、CMC、Alginic acid、PVP、離子交換樹脂 [cite: 19]。
  • 💡 筆記：咀嚼錠可不含崩散劑；發泡錠用水溶性崩散劑 [cite: 17]。

4. 潤滑、助滑與抗黏劑

目的：使顆粒流入錠模、降低模具磨損、提高表面亮度 [cite: 39]。

助滑劑 (Glidants)
  • 二氧化矽 (Fumed silicon dioxide)：最常用於直接壓錠 [cite: 40, 41]。
  • 滑石粉 (Talc)：用量小於 5% [cite: 42]。
潤滑劑 (Lubricants)
  • 水不溶性：硬脂酸鎂 (最常用，1%)、鈣鹽。過量會造成「雨衣現象」降低溶離 [cite: 45]。
  • 水溶性：PEG 4000/6000、月桂酸鹽，可改善雨衣現象 [cite: 45]。
抗黏著劑 (Anti-adherents)
  • 功能：減少顆粒黏附於沖模表面，防止出現凹隙 [cite: 46]。

5. 直接壓錠法專用 (Direct Compression)

  • 常用填充劑：Spray-dried lactose、微晶纖維素 (MCC)、Crystalline maltose [cite: 12]。
  • 助滑劑首選：二氧化矽 (Fumed silicon dioxide) [cite: 41]。
