🧫 凝膠劑定義與分類 ▶
定義
  • 又稱 jellies；小或大分子/分散系在水性媒液中加入膠凝劑 → 似膠凍狀半固體
  • 由無機小粒子或有機大分子被液體包覆且互相滲透組成之分散系架構的半固體系統
  • 精確定義：分散媒的運動被分散相粒子或巨分子形成的交叉立體網狀結構限制的半剛性系統
  • 例：tragacanth、CMC 凝膠由扭曲糾纏的分子鏈組成，以凡得瓦爾力纏在一起，形成結晶及無定形區
組成成分
  • 水（主要分散媒）
  • 膠凝劑：合成高分子（carbomer 934）、纖維素衍生物（CMC、HPMC）、天然膠（tragacanth）
  • 其他：活性成分、溶劑（乙醇、丙二醇）、防腐劑（methylparaben、propylparaben、chlorhexidine glyconate）、安定劑（edetate disodium）
  • 貯存：緊密容器，防止水分散失；避免冷凍
分類：單相 vs 二相系統
類型說明例子特性
單相 Single-phase巨分子均勻分散，與液體無明顯界線Androgel®、Carbopol 凝膠、tragacanth、CMC 凝膠、Poloxamer gel均勻、澄清
二相 Two-phase凝膠團由小而明顯微粒子凝絮物組成，稱 magma 或 milkMilk of magnesia（Mg(OH)₂）、Al(OH)₃ gel、Bentonite magma搖變性（thixotropy）
Emulgel：厭水藥物溶於油相（礦物油±paraffin）→ 製成 o/w emulsion → 再與 gel 混合。

⚗️ 凝膠劑製備原理 ▶
大有機分子凝膠製備方式
  • 分散法：分子分散於連續相（如 starch 加熱水分散）
  • 改變 pH 法：使分散分子交連（如 carbomers 加鹼中和 → 羧基解離 → 展開成凝膠）
  • 降低連續相法：以蔗糖製備的 jellies（濃縮水分）
永久性 vs 可逆性凝膠
類型結合力例子可逆？
永久性凝膠Primary valency forces（共價交連）交連型聚合物❌
可逆性凝膠Secondary valency forces（氫鍵、偶極-偶極、凡得瓦爾力）gelatin（冷卻成膠）；MC（加熱成膠）✅
記憶重點：
Gelatin：37°C 以上任何濃度均不成膠；降溫(<30°C)成膠。濃度越高，凝膠化溫度越高：10%(25°C)、20%(30°C)、30%(32°C)。
Methylcellulose（MC）：冷水易溶 → 加熱>50°C 成膠（與 gelatin 相反）。

🌿 聚電解質多醣（Natural Gums） ▶
1. 阿拉伯膠（Acacia）
  • 主要由 polyarabic acid 之鈣鹽（有時鎂鹽或鉀鹽）組成，分支狀
  • 用途：稠化劑、懸液劑/乳劑的保護性膠體
  • 乙醇可使 acacia、tragacanth、agar 從水溶液中沉澱
2. 果膠（Pectin）
  • 線性聚合物多醣類；用途：稠化劑、助懸劑、食品膠凝劑
3. 西黃耆膠（Tragacanth gum）
  • 膠漿在 pH 4–8 最安定
  • 防腐：0.1% benzoic acid 或 sodium benzoate；或 0.17% methylparaben + 0.03% propylparaben
  • 可用高壓蒸氣法滅菌（不破壞凝膠）
  • 製備：粉末加入強力攪拌之水中；可先用乙醇、甘油或丙二醇濕潤粉末再與水混合（避免團塊）

Q5111-2有關 tragacanth gum 之敘述，下列何者正確？
✅ 答案：B｜甘油（或乙醇、丙二醇）可用來濕潤 tragacanth 粉末，避免加水時結塊。A：可高壓蒸氣滅菌，不破壞。C：最安定 pH 4-8，非<3。D：乙醇可用來預先濕潤。

已儲存 ✓
4. 藻膠酸（Alginic acid）
  • 1–5% 作凝膠增稠劑；在水中膨脹至自身重量 200–300 倍而不溶解
  • 添加鈣鹽（如 calcium citrate）→ 交連 → 黏度↑
5. 藻膠酸鈉（Sodium alginate）
  • 濃度達 10% 可產生凝膠；>2.5% + 鈣鹽 → 安定凝膠（pH 5–10）
  • 水性製劑 pH 4–10 最安定；pH <3 沉澱
  • 電解質（低濃度）→ 黏度↑；高濃度電解質（NaCl ~4%）→ 鹽析
6. 瓊脂（Agar）
  • 溶於熱水，冷卻成凝膠；對水溶解度比 acacia 小
聚電解質多醣（Gums）配伍禁忌整合
  • 均含 −COO−，屬陰離子性聚電解質 → 與陽離子性界面活性劑形成複合共聚物
  • pH <3：−COO− 變成 −COOH → 溶解度↓
  • 重金屬離子 → 不溶性重金屬鹽沉澱
  • 過量甘油或乙醇 → 沉澱；大量單價陽離子（如 (NH₄)₂SO₄）→ 鹽析（可逆，加水再溶）
🔬 卡波美 Carbomer（Carbopol） ▶
化學與基本性質
  • Poly(acrylic acid)；由 acrylic acid 與蔗糖或 pentaerythritol 之 allyl ether 交連而得
  • 絨毛狀乾粉；濃度 0.5–2.0% 作膠凝劑
  • 1.0% 水分散液 pH = 2.5–3.0（酸性，必須加鹼中和才能成膠）
  • 數字越大 = 聚合分子越大（910 < 934 < 940 < 941…）
USP 收載型號
型號主要特性與用途
Carbomer 910安定懸液劑
Carbomer 934黏稠配方效果佳；持續釋放；局部凝膠
Carbomer 934p製藥界最廣用；適合口服或黏膜接觸
Carbomer 940晶瑩剔透水性/水醇性膠漿；最好不滴落特性；化妝品；乾眼症凝膠（vidisic gel）
製備凝膠：分散 → 中和（關鍵步驟）
分散：在快速攪拌液體漩渦中加入 carbomer；可用甘油/丙二醇/丁二醇先濕潤 中和（膠化）： 1% 分散體 pH 2.5~3.0 → 加鹼中和至 pH 6~7 → 黏度大增 最大黏度與澄明度：pH ≈ 7；可接受範圍：pH 4.5~11 中和劑選擇： 乙醇含量 <20% → NaOH 或 KOH 乙醇含量 ≈50% → Triethanolamine（TEA） 其他：碳酸鈉、氨水、硼砂
影響 Carbomer 黏度之因素
  • 乙醇↑ → 黏度↓、澄明度↓（需增加 carbomer 量補償）
  • 電解質 >3% → 崩解為水相，黏度大幅↓
  • pH <4.5 → 無法成膠（羧基未解離）

🧪 其他重要膠凝劑 ▶
澱粉（Starch）
  • amylose（10–20%，線狀）可溶於熱水；amylopectin（80–90%，枝狀）不溶於熱水，只吸水膨脹
  • 幾乎不溶於冷水；具 dilatancy（搖稠性）特性
  • 用途：稀釋劑、崩散劑；痱子粉（吸潮比滑石粉強）；易吸潮易腐敗

Q13106-1有關 starch 之敘述，下列何者錯誤？
✅ 答案：A（錯誤）｜澱粉不溶於冷水；amylopectin 在熱水中也只吸水膨脹不溶解。製備澱粉凝膠是透過加熱使澱粉糊化（粒子破裂吸水），非靠溶解。

已儲存 ✓
環糊精（Cyclodextrin）
  • α-CD：6 個葡萄糖；β-CD：7 個；γ-CD：8 個
  • 外親水、內疏水（中空筒狀）→ 包覆難溶藥物 → 形成包合物（inclusion complex）→ 助溶
膠體二氧化矽（Colloidal Silicon Dioxide, Aerosil®）
  • 吸濕性；不溶於水；可吸收大量水而不液化
  • 黏度大部分不受溫度影響（大部分不受溫度影響 = 考點）
  • pH 影響黏度：隨 pH↑ 而增加，pH 7.5 最有效；超過 pH 7.5 則↓
  • 低極性液體中成凝膠；可形成氫鍵之液體（如丙醇）中不成膠
Q15111-1以膠體二氧化矽（colloidal silicon dioxide）製備凝膠劑時，下列何者最易達到調整黏度之目的？
✅ 答案：A（酸鹼值）｜colloidal SiO₂ 黏度受 pH 影響（pH 7.5 最大）；溫度影響不大。

已儲存 ✓
明膠（Gelatin）
  • 冷水不溶，可吸水（5–10倍）膨脹；分散於熱水，冷卻形成凝膠
  • Type A：豬皮（酸處理），等電點 pH 7–9；乳化劑最適 pH 3.2（帶正電）
  • Type B：獸皮或骨骼（鹼處理），等電點 pH 4.7–5；乳化劑最適 pH 8（帶負電）
  • 為兩性聚電解質（amphoteric），非僅帶負電；可做保護性膠體、助懸劑、乳化劑、黏合劑、膠囊殼
Q16105-1Type B gelatin 之等電點（isoelectric point）在 pH 多少？
✅ 答案：B（pH 4.7–5）｜Type B（鹼處理）等電點 pH 4.7–5；Type A（酸處理）等電點 pH 7–9。

已儲存 ✓
Q17100-1下列關於明膠（gelatin）的敘述何者錯誤？
✅ 答案：C（錯誤）｜gelatin 為兩性聚電解質（amphoteric），依 pH 不同可帶正電或負電，並非僅帶負電。

Poloxamer（Pluronic®）
  • 聚氧乙烯-聚氧丙烯（PEO-PPO）嵌段共聚物；濃度 15–50%；熱敏感（thermo-responsive）
  • 常用：Poloxamer 188（F-68）、407（F-127）
  • Pluronic F-127®：毒性低，局部遞藥系統良好媒液；與 isopropyl palmitate + lecithin 合用 → PLO gel
Q18102-1下列何者是由 polyoxyethylene-polyoxypropylene 所組成之共聚合物，可用於製備凝膠劑？
✅ 答案：B（Poloxamer）｜Poloxamer = PEO-PPO 嵌段共聚物。Carbomer = poly(acrylic acid)；Plastibase = 5% 聚乙烯 + 95% 礦油；Veegum = 矽酸鎂鋁。

已儲存 ✓
普維酮（Povidone, PVP）
  • 非離子性；可溶於水及多種極性溶媒；較高分子量時 ~10% 可成凝膠
  • 與碘形成 PVP-Iodine（弱包合物，增加碘之溶解度及安定性）
  • 陽離子性藥物與 PVP 不會產生沉澱（PVP 為非離子性，無陰離子基）
Q19102-1陽離子性藥物與下列何種水溶性膠體不會產生沉澱反應？
✅ 答案：C（Povidone/PVP）｜PVP 為非離子性，無 −COO− 等陰離子基，不與陽離子藥物沉澱。A/B/D 含 −COO−（陰離子聚電解質）→ 與陽離子藥物形成沉澱。

Gelatin 可逆性凝膠化機制
冷卻（<30°C）： 巨分子動能↓ → 偶極-偶極交互作用↑ → 細長凝集物形成 → 分散媒被保留在網狀結構中 → 半固體 促進凝膠化（更強韌）：低溫 + 高濃度 + 高分子量 Gel point（凝膠化溫度）： 10% → 25°C；20% → 30°C；30% → 32°C ★ 37°C 以上任何濃度均不成膠 ★ 凝膠化溫度在等電點時最高 其他形成原理相同之 gums： agar、Irish moss、algin（藻膠）、pectin（果膠）、tragacanth

📜 法定乳漿劑 / 無機凝膠劑 ▶
皂土乳漿（Bentonite Magma N.F.）
  • 皂土（Bentonite）= 矽酸鋁黏土之鈉鹽；層狀結構，基本粒子小板狀
  • 不溶於水；分散後膨脹至原體積 12 倍；Sod. Bentonite 每克可吸水約 11 cm³
  • 製備：5% sod. bentonite 分散於純水機械攪拌；或熱水濕潤靜置 24h
  • 濃度 >4% → 搖變性（thixotropy）凝膠：靜置→凝膠，攪拌→溶膠（無限重複）
  • 機制：粒子帶正電荷及負電荷部分互相吸引 → 格架狀結構（類撲克牌架）
  • 應用：助懸媒液（calamine lotion U.S.P.）；面膜；化妝水粉體層
Bentonite 配伍禁忌：
• 陽離子性藥品 → 化學性吸著（不可）
• 非離子性水溶性藥品 → 物理性吸著 → 效能↓
• pH 9（9.5–10.5），具緩衝能力；pH<7 助懸力顯著↓ → 不可與酸同處方

氫氧化鋁膠漿（Aluminium Hydroxide Gel, U.S.P.）
  • 不溶性 Al(OH)₃ 和水合 Al(OH)₃ 組成；白色黏性水性懸液；含氧化鋁約 4%
  • 用途：制酸劑（10 mL 中和 13 meq 酸）；覆蓋胃表面
  • 製備：Al₂(SO₄)₃ + Na₂CO₃ + H₂O → Al(OH)₃↓ + Na₂SO₄ + CO₂
  • 配伍禁忌：與 tetracycline 在腸道中螯合，干擾藥效；貯存：密封，避免冷凍
鎂乳（Milk of Magnesia）
  • 含 Mg(OH)₂ 7–8.5%；制酸劑（5 mL 中和 10 meq 酸）；pH ≈ 10
  • 製備：NaOH + MgSO₄ → Mg(OH)₂↓；或 MgO + H₂O → Mg(OH)₂
  • 靜置時水分釋出 → 需搖勻；>35°C 降低凝膠結構；避免冷凍

💊 透皮吸收（Transdermal Permeation） ▶
皮膚結構（由外至內）
角質層（stratum corneum）← 主要障蔽，pH 4.5–6.5；親脂層；厚 10~15 mm ↓ 透明層（stratum lucidum） ↓ 顆粒層（stratum granulosum） ↓ 有棘層（stratum spinosum） ↓ 基底/發生層（stratum germinativum = basal cell layer）← 最內層 ↓（活組織：親水層） 真皮（dermis）：血管、毛囊、皮脂腺、汗腺；厚度 3–5 mm ↓（到達此層 → 吸收進入全身循環）
藥物穿透角質層的三條路徑
路徑說明適合藥物
①Transcellular path（直接穿透角質細胞）路徑最短；但角質蛋白難透非極性藥物
②Intercellular path（細胞間脂質雙層）★大部分藥物主要途徑連續脂質相；角質層主要障蔽非極性；小極性分子
③Appendage path（毛囊、汗腺、皮脂腺）繞過角質層；對小極性分子/離子重要極性分子、離子
大部分藥物穿透角質層主要途徑 = ②Intercellular path（細胞間脂質雙層）
Fick's Law — 透皮吸收動力學
flux = dM/(S·dt) = DSkc/h = PScd D：擴散係數 S：施用面積 k：分配係數（角質層/媒劑） c：藥物濃度 h：皮膚厚度 P：permeability coefficient = Dk/h ★ flux 正比：D、S、k（分配係數）、c（濃度） ★ flux 反比：h（皮膚厚度）
影響透皮吸收的因素
  • 藥物特性：分子量 100–800；水溶解度 >100 μg/mL；log P（octanol/water）在 1–3.5 間；未解離態穿透較好；候選藥物 flux ≈ 1 mg/cm²/d
  • 濃度↑ → flux↑；施用面積↑ → 吸收↑；接觸時間↑ → 吸收↑
  • 角質層厚度↑ → 吸收↓；封閉（occlusion）→ 水合↑ → 穿透↑
  • 藥物對皮膚親和力 > 對媒劑 → 吸收↑；若藥物與基劑親和性強 → 活性低 → 吸收↓
  • 極性藥物傾向走 intercellular path 或 appendage path（非 transcellular）
