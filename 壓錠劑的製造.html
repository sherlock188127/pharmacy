製法概論 Overview

四種製造方法

#方法特點
1濕粒法 Wet Granulation最廣泛使用；有液體黏合劑參與；適合大多數藥品
2合於一體造粒法 All-in-one流動床或噴霧乾燥；混合＋造粒＋乾燥一次完成

方法 2/3/4 的壓錠步驟均與方法 1（濕粒法）相同，差別只在於造粒過程。

為何需要造粒？

直接將粉末壓錠失敗的原因：
① 壓製時空氣介入＋粒子間黏合力太小 → 錠片太軟
② 粉末流動性不佳 → 錠片重量差異性太大

造粒目的（三大項）

  • ① 提供混合物由給料漏斗進入模內之流動性（減少重量差異）
  • ② 增加材料密度，改善在錠劑形成時之可壓性（Compressibility）
  • ③ 增強藥物組合的黏合性而提高硬度
注意：造粒目的不包含「使粒徑均一、無細粉」——過篩後仍有細粉，細粉是必要的（約 10–20%）

稀釋劑 / 填充劑 Diluents & Fillers

一般用稀釋劑（濕粒法 / 乾粒法）

★ Lactose 乳糖

  • 最受喜愛；選擇理由 → 溶解度（solubility）＋配伍性（compatibility）
  • 香甜、溶於水 → 不影響崩散
  • ⚠ 乳糖 ↔ Amine 類：在鹼性潤滑劑（Metal stearate）存在下 → Maillard reaction，錠片隨時間褪色

★ MCC（Microcrystalline Cellulose）

  • 一人多功能：稀釋 ＋ 黏合 ＋ 崩散 ＋ 助滑
  • 流動性極佳；不須另加黏合劑；崩散快速；物化生理惰性；配伍性高；水分含量低
  • 缺點：較貴，常添加 5–10% MCC 搭配其他稀釋劑

其他一般稀釋劑

  • Starch（澱粉）：便宜；吸水膨脹；乾澱粉可當崩散劑
  • Powdered sucrose（糖粉）：常用於咀嚼錠
  • DCP / Dicalcium phosphate：不溶；適固醇類、維生素錠
  • Calcium phosphate：⚠ 不可與 Tetracycline 合用（Ca²⁺螯合）
  • Calcium sulfate dihydrate：適合固醇類 & 對水敏感藥品
配伍禁忌重點：
・Tetracycline + Ca²⁺ 含量稀釋劑（DCP, Ca-phosphate, Ca-sulfate）→ 螯合 → 不可
・Lactose + Amine類 + 鹼性潤滑劑 → Maillard reaction → 變色

直接壓錠專用稀釋劑 DC Fillers ★必考

直打稀釋劑需具備 Cohesive（凝聚性） ＋ 良好流動性；原始澱粉和乳糖不能直接使用
DC 稀釋劑說明
Spray-dried lactose（噴霧乾燥乳糖）最常用；改善流動性 & Cohesive；原始乳糖不行
MCC（Avicel）★ 首選；多功能；不須加黏合劑
α-Monohydrate lactose 微晶結晶性 → 可 DC
Anhydrous lactose（無水乳糖）結晶性 → 可 DC
Pregelatinized starch（預凝膠化澱粉）處理過的澱粉才可；原始澱粉不行
DCP dihydrate / Di-Tab常用；⚠Tetracycline 禁用
Crystalline maltose（結晶麥芽糖）結晶性 → 可 DC
Granule mannitol咀嚼錠首選；流動性佳
Crystalline sorbitol結晶性 → 可 DC
Sucrose-invert sugar-corn starch mixture蔗糖-轉化糖-澱粉混合物
⚠ Maize starch（一般玉米澱粉）≠ DC 填充劑（國考陷阱！）
→ 預凝膠化的澱粉才可以
直打法主成分含量通常不超過總重 20–25%；超過則賦形劑無法足夠支撐 → 不易成型

潤滑劑 / 助滑劑 / 抗黏著劑 Lubricants · Glidants · Antiadherents

三種功能區分

類別功能代表
Lubricant 潤滑劑減少壓錠與彈出時錠面與模壁之摩擦；使錠片有光澤；減少黏模Magnesium stearate（最常用）
Calcium stearate, Stearic acid, Talc, Sodium stearyl fumarate
Antiadherent 抗黏著劑減少壓錠時銃壁與模子之黏附Talc, Corn starch, Fumed SiO₂, Magnesium stearate
Glidant 助滑劑改善顆粒本身的流動性（與模型無關）Fumed silicon dioxide（最常用）
= Colloidal SiO₂ = Aerosil® = Cab-o-sil®
用量：1% 以下
Talc, Corn starch

疏水性 vs 親水性潤滑劑

疏水性潤滑劑（最常用）：0.1–5%
代表：Mg stearate（最常用，約 1%）、Ca stearate、Stearic acid、Talc（加 5%）、Sodium stearyl fumarate
⚠ 用量過高 or 混合時間過長 → Raincoat effect → 延遲崩散與溶離
親水性潤滑劑（水溶性）：效果較差；用於需做澄清溶液的錠劑（如皮下錠、調劑錠）
代表：PEG 4000 / Carbowax 4000（蠟質特性 + 水溶性）
Sodium benzoate, Sodium benzoate + Sodium acetate, Sodium chloride, Leucine

潤滑劑使用注意

  • 需先用細篩網（60–100 號）篩過後撒在顆粒上 → 覆蓋效果才均勻
  • 使用 Twin shell 輕柔混合 → 避免產生太多細粉
  • 硬脂酸鎂偏疏水性；若要做發泡錠、澄清溶液錠 → 改用親水性潤滑劑
崩散劑 + 潤滑劑混合粉末稱為 Running powder（跑料粉）→ 可增進顆粒間緩衝，減少凝聚，促進崩散

濕粒法 Wet Granulation — 步驟 A → G

廣泛使用之方法；適合大多數藥品；有液體黏合劑（通常是水性）參與；造粒後需烘乾。
優點：適合劑量之劇藥；均勻著色（將染料溶在造粒液中）
缺點：步驟多、費時、不易自動化、批次間再現性差；不耐水/熱藥品不適用
A 稱重與混合 Weighing & Blending

主成分、稀釋劑、崩散劑先稱重 → 磨粉 → 過篩 → 混合均勻

稀釋劑選擇

  • 最受喜愛：Lactose（溶解度 & 配伍性）
    Spray-dried lactose 比普通乳糖流動性更佳
  • MCC 加入 5–15% 有助造粒/乾燥，減少錠面硬化或斑點

崩散劑添加時機

  • 在此步驟先加一半崩散劑 → 進到顆粒內部
  • 另一半保留至步驟 F（整粒後壓錠前）再加 → 顆粒間的位置
  • → 雙重崩散效果最佳
⚠ Calcium salts ↔ Tetracycline（螯合）；Lactose ↔ Amine 類（Maillard）
B 製備濕團塊 Preparing the Damp Mass

將液體黏合劑加到粉末混合物，以促進粉末粒子凝結，形成似麵團的濕塊

濕團塊的判斷

  • 捏起來可以成團，丟下去後散成大塊 → 剛好
  • 捏起來一團，丟下去QQ彈彈 → 加太多黏合劑
  • 捏起來手打開變一堆粉 → 加太少黏合劑

著色劑加入時機 考點

  • 最佳方式：將染料溶在黏合劑溶液中，造粒時加入 → 分散最均勻
  • 也可：水溶性染料吸附在澱粉或硫酸鈣上；不溶性染料與乾燥成分混合
斑點（Mottling）原因：乾燥過程中色素隨水分遷移
改善：① 低溫慢速乾燥
② 加 Tragacanth 1%, Acacia 3%, Attapulgite 5%, Talc 7%（色素遷移抑制劑）
③ 加 MCC 也有幫助（課本未提但老師補充）
C 濕團塊過篩成顆粒 Screening the Damp Mass into Granules
  • 濕團塊由篩網擠壓以製備顆粒，或用造粒機
  • 大粒子：#6–#8 號篩
  • 小粒子：#40–#80 號篩
球形化（Spheronization）：
Extruder → Spheronizer → 圓球形顆粒
MCC 是有效的稀釋劑 & 黏合劑（用於此製程）
D 顆粒乾燥 Drying the Granulation
  • 顆粒鋪於淺盤，溫控烘箱乾燥至一致重量或恆定水分含量
  • 溫度約 50–60°C（低溫慢速，避免色素遷移 & 影響藥品安定性）
  • 一般需 12 小時以上
  • Fluid bed drier（流動床乾燥器）：可在 1 小時內完成
乾燥步驟所控制的主要顆粒物性：
總含水量（水分含量）
顆粒最佳水分含量：0.5–1%
太乾 → 可能脆度不佳；太濕 → 黏模、頂裂
All-in-one 法（流動床造粒）：造粒 + 乾燥同時進行，一次完成（混合 → 噴黏合劑造粒 → 熱風乾燥）
E 乾燥過篩整粒 Sizing the Granulation by Dry Screening
  • 乾燥後之顆粒通過比製粒略小網目之篩來整粒
  • 整粒篩號 > 造粒篩號（篩號數字越大，洞越小）
  • 通常為 #12–#20 號篩
例：造粒用 8 號篩 → 整粒用 12 號篩
（乾燥後顆粒收縮，比造粒時小，所以用較小的洞篩）
考題：造粒用 20 號 → 整粒用 16 號

整粒目的

  • 篩出期望大小的顆粒（均一化）
  • 可使模洞（die cavity）快速被流動自如的顆粒充填
  • 避免太大顆粒留下空隙 → 產生不均勻錠片
整粒後有細粉是正常的（必要的），但細粉量不超過 10–20%。細粉可填充顆粒間縫隙，壓得更緊密。
F 添加潤滑劑（與崩散劑）並混合 Adding Lubricant & Blending
  • 乾燥的潤滑劑先以細篩網（60–100 號）篩過後撒在顆粒上 → 覆蓋更均勻
  • 用 Twin shell 輕柔混合，避免太多細粉
  • 此步驟也可加入剩餘的崩散劑（另一半）
崩散劑 + 潤滑劑混合 = Running powder（跑料粉）：可增進顆粒間緩衝，減少粒子凝聚性，促進錠片崩散
硬脂酸鎂混合時間越長 → Raincoat effect 越嚴重 → 溶離速率下降。
改善：混合時間不要過長；加少量界面活性劑
G 顆粒壓製成錠劑 Tableting of Granulation

詳見打錠機章節（第 09 節）。
方法 2/3/4 的壓錠步驟均與此相同。

07

乾粒法 Dry Granulation

適用條件：有效成分或稀釋劑必須有凝聚性（Cohesive）；或添加乾粉黏合劑
應用：適合遇水分（如 Aspirin）或高溫會降解之成分
無液體黏合劑參與
混合粉末 → 壓成大片/塊 → 粉碎 / 整粒 → 加潤滑劑混合 → 壓錠

① Slugging 重壓法（Double Compression）

  • 粉末稱重混合後，壓成大的平錠片（slugs），或直徑 1 英吋之圓粒
  • 手工或輾磨機粉碎 → 通過合意的篩網整粒
  • 添加潤滑劑 → 製成錠劑
  • 因為 Slug 形成速度不快，若產生過多粉末需篩出再粗壓及研磨
缺點：
・通常第一次壓錠也需加潤滑劑 → 二次添加潤滑劑
・經二次壓錠 → 成品較硬、溶離受影響
・比滾壓法效率低

② Roller Compaction 滾壓法

  • 粉末稱重混合後，以粉末壓緊器（Roller compactor）
  • 粉末在滾輪間以 1–6 噸之壓力增加密度 → 形成薄片（ribbon）
  • 再打碎、整粒、添加潤滑劑製成錠劑
  • 通常優於重壓法
  • 用於滾壓配方之黏合劑：MC 或 HPMC（6–12%）可產生良好硬度與脆度
滾壓法 vs 重壓法：
・兩者均為乾粒法（無液體）
・滾壓法效率較好，且比較常用
08

直接壓錠法 Direct Compression (DC)

最簡單；最不影響生體可用率；無需造粒；無液體黏合劑參與
優點：製程少；形成之錠劑有最佳藥品利用率（無黏合劑影響溶離；無二次壓錠）
主成分 + 稀釋劑 + 崩散劑 + 潤滑劑 → 混合均勻 → 直接壓錠

直接壓錠的條件與限制

可直接壓錠的藥品（本身有 Cohesive）

NaClKClAspirinMethenamineAmmonium chloride

沒有 Cohesive 的藥品 → 依賴賦形劑

  • 主成分含量通常不超過總重 20–25%
  • 超過 → 賦形劑不夠力 → 不易壓製成型
賦形劑若預先造粒，需考慮與粉末藥物之混合均勻與Segregation（分離層化）問題

直接壓錠的缺陷與改善

層裂與破裂

  • 原因：空氣陷入 → 壓力釋出時膨脹 → 破裂或層裂
  • 改善：加壓式或引導式給料器（forced or induced feeders）→ 減少空氣陷入，使充填粉末更緻密

頂裂（Capping）

  • 空氣陷入
  • 含太多細粉（細粉佔顆粒重量 10–20% 以下是允許的，過多則導致頂裂）
  • 銃未清潔乾淨；銃不完全光滑
  • 老化或貯存不當
  • 改善：減低入料速度（最常考）
直打法細粉含量最適：10–20%（細粉過少→空隙大；過多→頂裂）
09

打錠機 Tablet Machines

① 單銃式壓錠機（Single Punch）

一組銃與模；速度較慢；適合小量打錠或預處方

①下銃下降至固定位置
↓
②顆粒充填進模洞
↓
③刮去過量顆粒使其平
↓
④上銃壓下（只有上銃動）→ 形成錠片
↓
⑤上銃往上撤回；下銃上升推錠片至平台
↓
⑥掃除錠片至收集容器

② 迴轉式壓錠機（Rotary Tablet Machine）

多組銃與模；生產速度快；高速機可達每分鐘 10,000 錠以上

①多組銃和模連續旋轉
↓
②顆粒充填進模洞
↓
③下銃上升至固定位置（校正充填量）
↓
④上下銃同時壓縮（與單銃不同！）→ 形成錠片
↓
⑤上銃撤回；下銃上升推出錠片
壓點（Press point）：
・前壓點（小滾輪）→ 輕輕壓，讓空氣排出
・主壓點（大滾輪）→ 正式壓縮
可安裝雙壓點 → 速度加倍

★ 重量 vs 硬度 調整 最常考

欲調整調整部位說明
硬度 Hardness上銃（Upper punch）上銃壓得越深 → 壓力越大 → 錠片越硬
重量 Weight下銃（Lower punch）下銃降得越低 → 充填量越多 → 重量越重
⚠ 調整重量時，壓力也必須同時改變！
填充量增加 → 下銃更遠 → 原壓力不夠 → 上銃也要加大壓力
填充量減少 → 壓力需降低
→ 實驗課老師帶你一起調重量和硬度，調好後再連續打錠
重量差異原因：
・下銃下降幅度不一 → 重量差異大（主因）
・上銃下降幅度不一 → 較不影響重量差異
・顆粒流動性不良；顆粒大小差異大

壓力的作用 — 顆粒變形過程

階段說明
1. 固結（Consolidation）粉末顆粒重新排列，採更有效率的填充順序
2. 彈性/可逆變形去除力後粉末完全恢復；多數藥物粉末此階段持續時間很短
3. 塑性/不可逆變形 ★片劑形成最關鍵的階段；施力過大 → 脆性斷裂；施力太快 → 斷裂脫粘
Dwell time（停留時間）：維持最大壓縮點的時間
dwell time 越長 → 塑性流動（plastic flow）越充分 → 錠片強度增加
高速打錠 → dwell time 不足 → 層裂/頂裂 → 解決：降低壓錠速率
打錠壓力大小最重要影響的錠片物性：硬度（Hardness）

重量與硬度的調整流程

料斗加入少量顆粒 → 手轉機器，調節壓力至形成錠片 → 調整錠片重量（調下銃） → 同時調整壓力（調上銃） → 達到所需重量 & 硬度 → 填充料斗 → 連續壓錠 → 每 15–30 分鐘定期檢查硬度和重量
