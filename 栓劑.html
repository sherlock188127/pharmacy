01 基本概念 ▼
1.1 定義
栓劑 Suppository
固體劑型，主成分分散於適當基劑，模製或用其他方式成形，供塞入直腸後經熔化、軟化或溶解發揮局部或全身性效應。
塞劑 Inserts
固體劑型，供塞入自然發生的（非手術的）體腔——除了口腔和直腸以外，包括陰道和尿道。
藥用棒劑 Sticks
局部外用給藥的方便形式，涉及化粧品相關產品。

1.3 直腸給藥優勢
考點：「完全避免首渡效應」是錯的！ 只能部分（約 50~70% 以上）避免肝臟首渡代謝。
  • 至少部分可避免首渡效應 (first-pass effect)，可產生較高血中濃度
  • 可避免胃腸道酵素破壞（直腸酵素仍存在，但較少）
  • 可給與比口服稍大的藥物劑量
  • 對口腔或胃腸黏膜有刺激效應的藥物，可給藥
  • 不愉快味道或氣味的藥物可選用直腸給藥
  • 生病孩子拒絕口服，或有噁心、嘔吐、失去意識的病人
  • 上胃腸道疾病干擾藥物吸收時之替代
  • 可作為注射劑的替代，達快速全身性效應
全身作用代表藥品（栓劑達全身效應）
diazepam metronidazole progesterone aminophylline morphine chlorpromazine indomethacin diclofenac ketoprofen naproxen
1.4 栓劑缺點 / 不常使用之理由
  • 商用栓劑劑量缺乏彈性
  • 來取調劑費用可能較貴
  • 重複給藥易導致直腸黏膜出血、潰瘍、炎症
  • 治療區間狹窄的藥物（如 aminophylline）需注意
  • 子彈形栓劑塞入後會上升至直腸乙狀結腸和降結腸，建議不在睡前使用
  • 排便會阻礙藥物吸收
  • 直腸吸收表面積遠小於小腸（無絨毛）
  • 直腸體液（2–3 mL）遠少於小腸（1–3 L）
  • 某些藥物可被直腸微生物菌落降解
  • 直腸給藥所需劑量可能大於口服：Lincomycin、Chloral hydrate（直腸需 4 倍）；Phenytoin（直腸需 3 倍）
1.5 局部作用 vs 全身作用

局部作用

  • 痔瘡栓劑（局部麻醉劑、血管收縮劑等）
  • 甘油栓劑 (glycerin suppository)：緩瀉
  • 陰道：避孕 nonoxynol-9、抗真菌 miconazole
  • 尿道：抗菌或局部麻醉
  • 棒劑：水化/潤膚、抗菌、防曬、止癢

全身作用

  • prochlorperazine、chlorpromazine：止吐、安神
  • oxymorphone HCl：opioid 鎮痛
  • ergotamine tartrate：偏頭痛
  • indomethacin：NSAIDs
  • ondansetron：止吐

03 栓劑的基劑 ▼
3.1 理想基劑性質
  • 室溫固態；體溫下軟化、熔化或溶解
  • 無藥物交互作用，不影響藥品釋出
  • 不刺激直腸黏膜、不引起排便運動
  • 貯藏時安定，無不愉快氣味
  • 高熔點基劑可加入降低熔點之藥物（如 camphor 樟腦、chloral hydrate 水合三氯乙醛、menthol 薄荷醇、phenol 酚、thymol 百里酚及揮發油）

3.3 可可脂（Cocoa Butter / Theobroma Oil, NF）⭐ 重點
基本性質
  • 室溫：黃白色固體，有淡淡巧克力味
  • 熔化點：30–36℃；凝固點 27.5℃；軟化點 32℃
  • 肛門栓劑的好基劑；不適合作陰道或尿道栓劑（熔融油脂不與黏膜分泌液互溶，會漏出）
  • 缺點：無法吸收水性溶液；易酸敗
成分組成
考點：飽和脂肪酸中以「硬脂酸 stearic acid」和「棕櫚酸 palmitic acid」為主！ 油酸是最多的單不飽和脂肪酸。
脂肪酸類型含量主要成份
飽和脂肪酸 (saturated FA) 57–64% 硬脂酸 (stearic acid)、棕櫚酸 (palmitic acid)（主）；少量十烷酸 (capric acid)、肉豆蔻酸 (myristic acid)、花生酸 (arachidic acid)、月桂酸 (lauric acid)

⭐ 晶型考點整理
晶型 穩定性 熔點 凝固點 考點說明
γ 最不安定 18℃ — 加熱超過熔點後冷卻，第一個出現的晶型；室溫不易凝固
α 亞穩定 22℃ ≈ 20℃ ★ metastable form；室溫不能固化；凝固點約 20℃（常考！）
β' 不安定 27℃ — 靜置後由 α 轉換而來

降低可可脂熔點的物質 → 需加硬化劑
⚠️ 降低可可脂熔點的物質
精油 (volatile oils)、木溜油 (creosote)、酚類 (phenols)、水合三氯乙醛 (chloral hydrate) → 熔點太低，無法製成固體栓劑

▶ 解決：加固化劑（硬化劑）
   • 鯨蠟 (cetyl ester wax)：約 20%
   • 蜂蠟 (beeswax)：約 4%
   • 熔合法製備時可加少量硬脂酸鋁 (aluminum stearate)

PEG 優勢
  • 熔點 37–63℃（> 體溫），遇體溫不易熔化，慢慢溶解在體液中 → 藥物緩慢釋放
  • 不需冷藏；固體性質，指尖不會熔化
  • 不易被微生物污染
  • 若 PEG 類栓劑水量 < 20%，使用前必須浸水，以減少刺激黏膜
⚠️ PEG 配伍禁忌（常考）
  • 與以下藥品呈禁忌 (incompatible)：
    benzocaine 苯佐卡因、iodochlorhydroxyquine、sulfonamides 磺胺類、aspirin 阿斯匹林、ichthammol、silver salts 銀鹽、tannic acids 鞣酸

    sodium barbital、salicylic acid 水楊酸、camphor 樟腦

  • 會降低某些抗生素抗菌活性，特別是青黴素 (Penicillin)和桿菌肽 (bacitracin)
04 中華藥典規定 ▼
4.1 一般定義與常用基劑
  • 常用基劑：可可脂、甘油明膠、氫化植物油 (hydrogenated vegetable oil)、各種聚乙二醇之混合液，及聚乙二醇之脂肪酸酯
  • 可可脂宜供製作內痔栓劑（抑制刺激）；體溫迅速熔化，但不能與體液互溶，不易將脂溶性藥品釋出
  • 聚乙二醇為製備含防腐劑之藥品製劑最適當基劑
4.2 溶離試驗裝置
考點：中華藥典 = 裝置 IV（川流槽式法）；USP = Apparatus 1 & 2
藥典裝置
中華藥典（ChP）裝置 IV（川流槽式法）：適合多劑量劑型、軟明膠膠囊、栓劑、貯庫型產品及懸浮型延釋劑型
USPApparatus 1（轉籃法）、Apparatus 2（槳葉法）

5.1 物理狀態、粒子大小、溶解度
變因說明
物理狀態
Physical State		固體藥品：粒子大小重要（不溶性藥物尤其）；液體藥品：需形成乳劑或加增稠劑；半固體：與基劑混合前先與增稠劑混和
粒子大小
Particle Size		水溶性佳：粒子大小影響小；水溶性差：減小粒子大小可提升表面積增加溶離速率（但粒子太細：增加基劑黏度，流動困難）
溶解度
Solubility		溶解度佳：均質性好，但親和性太大→延遲釋放；溶解度差：形成「乳劑」或「懸液劑」，需持續攪拌維持均質
5.2 黏度、脆度、體積收縮
變因說明
黏度
Viscosity		 基劑黏度低 → 可能需加助懸劑（如矽膠 silica gel，25 mg/栓劑）確保藥物分散至固化
基劑黏度高 → 藥物釋放速率可能緩慢（擴散速率較慢）
脆度
Brittleness		 非基劑材料超過 30% → 通常產生脆性
合成脂肪基劑（高 stearate 硬脂酸化合物濃度或高度氫化）→ 比較脆
急速冷卻也會引起破碎 → 確保模具溫度接近熔化基劑溫度可預防
體積收縮
Volume Contraction		 冷卻時熔化物體積收縮 → 後面產生洞（不宜）
處理：① 熔化物接近凝固點再倒入模；② 過量充填，冷卻後用刀片刮除過量
5.3 藥物釋放速率（Drug Release Rate）⭐ 常考
考點：水溶性藥 + 油性基劑 = 最快！油溶性藥 + 油性基劑 = 最慢！
藥品基劑釋放速率原因
水溶性藥品 (water-soluble)油性基劑（可可脂）(oily base)最快（第 1）水溶性藥品不溶於油，基劑熔化後藥品易釋出至水性體液
油溶性藥品 (oil-soluble)水溶性基劑（甘油明膠、PEG）(water-miscible base)中等（第 2）擴散作用
水溶性藥品水溶性基劑中等（第 2）擴散作用
油溶性藥品油性基劑最慢（第 3）藥品與基劑親和性太大，延遲釋放
5.4 特殊問題
  • 植物浸膏劑不易研入基劑：用小量熔化基劑研調使之濕潤
  • 硬的結晶藥品：先粉碎微細化後研合，或用少量溶媒溶解後吸收於基劑
  • 水溶性藥品需用油脂性基劑：用羊毛脂 (lanolin)吸收後併入
  • 過量粉末研入油溶性基劑：先與礦油 (mineral oil)研合後再研入
  • 過量粉末研入水溶性基劑（PEG）：提高低分子量 PEG 使用比例
  • 揮發油或精油降低熔點：先以乳糖 (lactose) 或碳酸鎂 (magnesium carbonate) 吸收後再研入基劑

6.1 栓劑模（Suppository Molds）
項目說明
模具材料不鏽鋼、鋁、銅（黃銅）、塑膠（玻璃不常見）；鎳-銅合金製優於鋁製
潤滑劑需求 可可脂（ChP）：需潤滑劑（內壁塗甘油）；Ansel's：不常需要
甘油明膠：需礦油 (mineral oil)作潤滑劑
PEG、Witepsol、Wecobee：不需潤滑劑（冷卻收縮可自行脫模）
模具校正不同基劑密度不同 → 必須校正每個栓劑模，確保每粒正確藥量
6.2 計算栓劑所需基劑——三種方法
考點：三種計算法的名稱 + 各自的計算邏輯。密度因子法最常用於計算替代量。
方法 1：劑量取代因子法（Dosage Replacement Factor Method）
公式（以可可脂為標準基劑，ƒ 值 = 1）
ƒ = [100(E − G) / (G × X)] + 1

ƒ = 劑量取代因子 (dosage replacement factor)
E = 純基劑之栓劑重量 (g)
G = 有效成分含 X% 之栓劑重量 (g)
X = 有效成分百分比 (%)

解 G = 含藥栓劑成品重量（即所求）
方法 2：密度因子法（Density Factor Method）
公式
DF = B / (A − C + B)

A = 空白基劑平均重量 (g)
B = 每粒栓劑中藥物重量 (g)
C = 含藥栓劑的平均重量 (g)

藥品之基劑取代值 = B / DF
每粒基劑用量 = A − (B / DF)
每粒栓劑總重 = 每粒基劑用量 + B
方法 3：佔有體積法（Occupied Volume Method）
步驟（製備 N 粒）
① 每粒空白基劑重量 × N = 栓劑總量
② 密度比 = 藥品密度 / 基劑密度
③ 藥品取代基劑量 = 藥品總量 / 密度比
④ 所需基劑重量 = 栓劑總量 − 取代量
⑤ 活性藥物量 = 藥品/粒 × N
