⬡ 整體特性與基本規範
吸收與生體可用率

吸收速度比口服、栓劑快，生體可用率接近 100%。

外觀要求

須澄清透明，不可添加色素 / 著色劑，以免干擾雜質判讀。

滅菌 & 熱原

製程必須滅菌。熱原（內毒素）限量 ≤ 0.25 EU/mL。★ 考 4–5 次

全面檢查

採 100% 逐支檢查，非抽樣。

⬡ 玻璃容器 Type I–NP
Type材質適用範圍特性
Type I Borosilicate glass（硼矽玻璃） 任何目的（最廣） 膨脹係數最小、耐變性最大
Type II 處理過的蘇打石灰玻璃 乾粉、油溶液、酸性水溶液 比 Type III 穩定
Type III 蘇打石灰玻璃 乾粉、油溶液 易溶出氧化物較多
Type NP 一般蘇打石灰玻璃 不得供注射用 —
記憶口訣：數字越小功能越廣；Type I 最強最廣、NP 最弱不能用。
soda-lime glass：Type II、III、NP；Type I 才是 borosilicate。
小體積注射劑（SVPs）：用 Type I。
安瓿（Ampule）裂隙試驗
  • 裂隙試驗僅適用安瓿，用色素溶液測試是否滲漏或熔封完整
  • 色素：Methylene blue（亞甲基藍） — 陽離子型介面活性劑

111-1 常用於藥品容器之 type I、II、III 等三類玻璃之特性，下列何者最適當？ ▶
✓ (A) type I 玻璃具最小的熱膨脹係數
(B) type I 和 type II 均屬 soda-lime（錯：I 是 borosilicate）
(C) type III 重金屬游離最少（錯：I 最少）

(B) Type III 適用於乾粉及油溶液 ✓

(D) Type I 為矽酸硼玻璃 ✓

106-2 有關玻璃材質容器的敘述，下列何者錯誤？ ▶

⬡ 熱原（Pyrogen）★ 超高頻
來源與效力
  • 微生物在水溶液的代謝物
  • G(−) 陰性菌效價最強（LPS）
  • 最大污染源：水（非器具或操作人員）
人體反應
  • 發熱 → 血管擴張 → 低血壓
  • 淋巴球數下降
  • CRP（C反應蛋白）上升（發炎指標）
活性部位

內毒素活性在其脂質部分（Lipid portion），非蛋白質。

容量規定

注射量 ≥ 5 mL → 不得含熱原
< 5 mL → 可能不含熱原

限量：≤ 0.25 EU/mL

去除熱原方法
方法條件備註
乾熱滅菌法160°C / 2 小時最常用
氧化劑法KMnO₄（高錳酸鉀）+ Ba(OH)₂Ba(OH)₂ 增強效果
逆滲透法—有效
陰離子交換樹脂—有效
高壓蒸氣／濕熱法—無法去除熱原
內毒素閾值（各注射途徑）
注射途徑閾值
肌肉 / 靜脈 / 皮下5 EU/kg/hr
鞘內注射（Intrathecal）0.2 EU/kg/hr（最低）

⬡ 家兔試驗（Rabbit Test）
條件規定記憶
體重≥ 1.5 kg，健康成年抓 3 隻
正常體溫38.9–39.8°C達美樂電話 3939889
溫度計刻度 0.1°C；插入肛門 7.5 cm
注射部位耳靜脈★ 至少考 3 次
注射量10 mL/kg注射都跟十有關
注射時間≤ 10 分鐘十分鐘
試驗後休息無反應 → 2 天；有反應 → 2 週有無都跟 2 有關
去熱原器具250°C 乾熱 30 分鐘
結果判定
試驗判定條件
第一次（3 隻） 全部 3 隻體溫均 未超過 0.5°C → 無熱原
有 ≥1 隻超過 → 進行第二次試驗
第二次（共 8 隻） 超過 0.5°C 不超過 3 隻，且
全部 8 隻體溫上升總和 ≤ 3.3°C → 無熱原
NSAID 干擾：NSAIDs 具解熱作用，會壓低家兔體溫，使結果失準 → 不可用家兔做熱原試驗。

⬡ BET / LAL 試驗（細菌內毒素試驗）
基本特性
  • 全名：Bacterial Endotoxin Test / Limulus Amebocyte Lysate
  • 體外試驗（in vitro）
  • 內毒素來源：大腸桿菌（E. coli）
  • 試劑：鱟（ㄏㄡˋ）酵素試劑
  • 判定：形成凝膠（B、C 同出現時以凝膠為準）
優點
  • 反應迅速
  • 敏感度高
  • 操作簡單
  • 體外操作，不需動物
LAL 試驗干擾藥品
類別藥品記憶
完全不能用 LAL Vancomycin、Sulfisoxazole、Oxacillin 不能反鎖哦（Van、Sul、O）
需稀釋兩倍以上
（不能原液）		 Meperidine、Promethazine、Diphenhydramine、Thiamine 死媒婆帶賽（釋 Me、Pro、Di、Thi）
不需稀釋 Pentobarbital 布希偏頭痛（不需 Pento～tal）
