⬡基本概念
定義 & 語源

預期腸外給藥的無菌、無熱源製劑。

Parenteral：希臘文 para（外）＋ enteron（腸）

最早法定注射藥品：1874 年 皮下注射 morphine 溶液

整體特性
  • 吸收速度快，生體可用率接近 100%
  • 須澄清透明，不可添加著色劑（干擾雜質判讀）
  • 必須滅菌；熱原限量 ≤ 0.25 EU/mL ★ 4–5次
  • 採 100% 逐支全面檢查（非抽樣）
  • 多劑量容器須加入抑菌劑（防腐劑）
降低吸附設計
  • 添加白蛋白
  • 縮小輸注導管內徑
  • 縮短輸注導管長度
中華藥典特殊藥品
藥品規定
Vasopressin（加壓素）注射劑須冷藏避光儲存；注射液不得冷凍
Methocarbamol（美索卡巴莫）注射液溶於 Polyethylene glycol 300（PEG 300） 水溶液

靜脈注射（IV）重點
  • 起效最迅速，可準確即時達到最佳血液濃度；缺點：無法回收已注入藥物
  • 肘前靜脈並非首選（活動量大，外滲風險高）；斜面朝上插針，方向與血流一致
  • 常見流速：42–150 mL/h
  • 輸注刺激性溶液易促成血栓（thrombus）→ 滯留血管形成栓塞（embolus）
靜脈注射脂肪乳劑（IV Emulsions）
適應症需長期腸外營養（通常超過 5 天）患者之熱量和必需脂肪酸來源
成分大豆油（≤30%）＋ 蛋黃卵磷脂（egg yolk phospholipids）作為乳化劑 ＋ 含甘油之注射用水
常見產品Intralipid 20–30%（Baxter）；Liposyn II/III 10–30%（Hospira）
給藥可經由週邊靜脈或中心靜脈輸注施用
肌肉注射（IM）重點
  • 效果慢於 IV，但作用時間較長；可施打水溶液、油溶液或懸浮液（後兩者吸收較慢）
  • 吸收速度：溶液中藥物 > 混懸液；水性製劑 > 油性製劑
  • 注射位置：成人用臀大肌上面外側（最常用）；嬰兒避免臀部（可能靠近坐骨神經），用上臂三角肌或大腿中外側肌
  • 用量限制：臀部肌肉最多 5 mL；手臂三角肌最多 2 mL
  • 可能副作用：神經傷害、膿腫、囊腫、血栓、血腫、皮膚脫落、癱瘓
Z型軌技術（Z-track Technique）：適用可能染色（如 iron dextran）或組織刺激性藥物（如 diazepam）。注射前拉緊皮膚向側方移動 → 插針回吸確認無回血 → 緩慢注射後拔針 → 放開皮膚形成Z字型通道，防止藥液滲入皮下組織。
皮下注射（SC）重點
  • 注射部位：上臂外側表面鬆散組織間隙、腿部外側或下腹部
  • 注射量：舒適量為 1.3 mL；大於 2 mL 易引起疼痛
  • 不適合 SC 的情況：刺激性藥物、黏稠懸液、硬結 / 脫皮 / 膿腫
皮內注射（ID）重點
  • 將藥物淺層注射於表皮與皮下組織間的真皮層
  • 常用於診斷用藥、脫敏 / 免疫（如結核菌素試驗、過敏測試）
  • 注射部位：前臂前側
  • 注射量：僅需 0.1 mL（最少）
特殊通道（Central Venous Catheter）
  • 適用需長期重複注射：化療、長期抗生素、TPN；使用數天至數個月
  • 不用時以肝素維持導管暢通
  • 導管材質：PVC、Teflon（聚四氟乙烯）、Polyethylene（在X光可見）
  • 常見：Broviac、Hickman 導管（注射端口未植入皮下）
  • 風險：導管斷裂、穿刺部位感染、導管性敗血症

⬡注射用水 USP（6種）
1. Water for Injection USP（注射用水）
  • 大型注射劑製造商最常用的溶劑
  • 經蒸餾或逆滲透純化，總固體含量不超過 1 mg/100 mL（10 ppm）
  • 不得含有添加物質（抗菌劑、防腐劑、抗氧化劑均不可加）
  • 雖不要求無菌，但必須無熱原 ★ 超重要
  • 用於製造注射產品，製備後再進行滅菌
  • 儲存在密閉容器中，收集後 24 小時內使用
  • 應收集在無菌且無熱原的容器中，通常為玻璃或玻璃襯裡容器
2. Sterile Water for Injection USP（滅菌注射用水）
  • 注射用水經滅菌處理
  • 不得含抗菌劑
  • 容量不得超過 1000 mL
  • 一般包裝在單劑量容器中
  • 必須無熱原；內毒素不得超過 0.25 USP EU/mL
  • 1000 mL 瓶裝不可靜脈注射（無等張性，低張→紅血球吸水膨脹→溶血）
  • 使用時需加入 NaCl、葡萄糖等調整滲透壓成等張後，才可靜脈輸注
  • 例如：Sterile Ampicillin Sodium USP 乾粉 → 加入無菌注射用水溶解
3. Bacteriostatic Water for Injection USP（抑菌注射用水）
  • 含一種或多種抗微生物劑之注射用水（看到「抑菌」就代表有加抗微生物製劑）
  • 用於小量注射液（≤30 mL）
  • 標籤須列出抗微生物劑名稱與比例
  • 標示必須包含：「新生兒不可使用（NOT FOR USE IN NEONATES）」
  • 新生兒禁用：含有 Benzyl alcohol 0.9%，新生兒肝臟解毒能力有限，可能致死
4. Sodium Chloride Injection USP（氯化鈉注射液）
  • 含氯化鈉於注射用水中的無菌等張溶液
  • 不含抗菌劑，但每公升含 Na⁺、Cl⁻ 各約 154 mEq
  • 可用作胃腸外給藥藥物溶液或懸浮液的無菌媒劑之載體
  • 亦可用於導管或靜脈輸液管沖洗以保持通暢
5. Bacteriostatic Sodium Chloride Injection USP（抑菌氯化鈉注射液）
  • 0.9% 氯化鈉在注射用水中的無菌等滲溶液，含一種或多種抗菌劑
  • 容量需 <30 mL 容器使用
  • 作為載體時，需確認所添加藥劑是否與防腐劑或氯化鈉相容
  • 可用於導管沖洗或靜脈輸液管維持通暢
  • 新生兒禁用，肝臟尚未成熟，苯甲酸和未代謝苯甲醇可能蓄積
  • 標籤必須警告：「帶有新生兒不可使用的警告」
6. Ringer's Injection USP（林格氏注射液）
  • 含氯化鈉、氯化鉀、氯化鈣於注射用水之無菌溶液
  • 可作為其他藥物媒劑或單獨作為電解質補充劑或血漿增容劑
  • 乳酸林格氏注射液（Lactated Ringer's Injection USP）：含乳酸鈉（Sodium Lactate），可用於全身鹼化劑與電解質補充劑（如結石病人體內較酸，可用鹼化劑緩解）

⬡注射用水 TWP IX（5種）
1. 純淨水（Purified Water）
  • 本品不得含有其他附加物質
  • 不得供作靜脈注射用製劑之調製；靜脈注射用製劑應使用注射用水、抑菌注射用水或滅菌注射用水
  • 要求：總有機碳、水導電度、微生物限量（每 mL 不得超過 100 CFU）
  • 標誌：應標示「不得供靜脈注射用」
2. 無菌純淨水（Sterile Purified Water）
  • 本品為經滅菌處理並適當包裝之純淨水
  • 本品不含抗菌劑
  • 不得供注射或調製注射劑之用
  • 要求：易氧化物質、無菌試驗、水導電度（≤10 mL → ≤25 μS/cm；>10 mL → ≤5 μS/cm）、總有機碳
  • 標誌：標示「不得供靜脈注射」；不可直接與乾粉針劑混合，進行皮下注射（需達注射用水等級）
  • 中華藥典未要求必須無內毒素（因不用在注射）
3. 注射用水（Water for Injection）
  • 本品為標準飲用水經蒸餾或更佳之純化（如逆滲透）過程製成
  • 需經由滅菌，以供體內注入製劑之用
  • 主要用途為藥廠製備注射劑（滅菌後使用）
  • 細菌內毒素：每 mL 不得超過 0.25 IU/mL
  • 微生物限量：每 100 mL 不得超過 10 CFU
  • 水導電度（大批量）、總有機碳均須符合規定
  • 標誌：標示「不含抗菌劑或其他物質」，並標示「不得供靜脈注射用」（因未調等張）
4. 無菌注射用水（Sterile Water for Injection）
  • 本品為經滅菌並適當包裝之注射用水
  • 本品不得含有抗菌劑或其他附加物質
  • 細菌內毒素：不得超過 0.25 IU/mL
  • 水導電度：≤10 mL → ≤25 μS/cm；>10 mL → ≤5 μS/cm
  • 包裝：置於注射劑單劑量玻璃或塑膠容器，容量不得超過 1 L；玻璃容器應為 Type I 或 Type II
  • 標誌：「不含抗菌劑或其他附加物」；如未經添加適當之成分調節為等滲透壓，不得供血管注射之用（若加氯化鈉調成等張，則可）
5. 無菌灌洗用水（Sterile Water for Irrigation）【中華藥典特有】
  • 本品係將注射用水，以適當灌洗液劑容器包裝所成之滅菌灌洗液（血液透析用）
  • 本品不含抗菌劑或其他附加物
  • 細菌內毒素：不得超過 0.25 IU/mL
  • 包裝：可超過 1000 mL 容量之單劑量、易傾倒之玻璃或塑膠容器；玻璃應為 Type I 或 Type II
  • 標誌：應顯著註明「僅供灌洗使用（外用，超過 1000 mL），不得供注射之用」

⬡細菌內毒素試驗 BET / LAL
基本特性
  • 全名：Bacterial Endotoxin Test（BET） / Limulus Amebocyte Lysate（LAL）
  • 1956 年 Bang 發現：美洲鱟（Limulus polyphemus）的血液遇到 G(-) 菌會產生凝膠反應
  • 體外試驗（in vitro）；比家兔試驗更敏感且可定量
  • 試劑：鱟（ㄏㄡˋ）酵素試劑（鱟阿米巴樣細胞溶解物）
  • 內毒素來源：大腸桿菌（E. coli）
  • 對 G(-) 內毒素有效；對 G(+) 無反應
優點
  • 反應迅速
  • 敏感度高
  • 操作簡單
  • 可避免動物使用
  • FDA 已認可作為家兔試驗替代法
TWP 三種細菌內毒素檢驗法
方法原理說明
凝膠法（gel-clot technique）最基本，觀察是否形成凝膠利用內毒素與 BET 試劑反應形成凝膠，進行限量或定量試驗；不一致時以此法為最終判定依據
濁度法（turbidimetric technique）內毒素與試劑反應後產生混濁利用光度定量法測定混濁變化（內毒素含量越多混濁越多）
呈色法（chromogenic technique）加入顏色基質，與內毒素反應後產生顏色利用光度定量法檢測合成肽色原複合物裂解時產生之顏色變化
三種方法結果不一致時，以凝膠法為最終判定依據。試驗過程中應避免受內毒素污染。

⬡ASHP 無菌產品危險水平分級
依美國衛生系統藥師協會（ASHP）出版之《藥局製備無菌產品指引》，將藥局製備的無菌產品區分為 3 個危險等級。
等級適用範圍記憶
低度風險（Level 1）大容量注射液容器（LVPs）大體積 → 毒性高也被稀釋
中度風險（Level 2）TPN（全靜脈營養）、眼用製劑
高度風險（Level 3）使用非無菌原料製備無菌產品（從終端滅菌前之非無菌成分調配的產品）有菌原料 → 高風險
