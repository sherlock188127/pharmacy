一 錠劑分類 Classification
依製作方法
壓製錠 Compressed tablets
  • 上下杵於鋼模中，以高壓將粉末或顆粒壓製成錠
  • 杵及模之設計可製成不同樣式
  • Multiple compressed（多層壓製錠）
    隔開不相容成分；分段釋放（stage release）；不同顏色產生獨特外觀
模製錠 Molded tablets
  • 藥品與稀釋劑（乳糖 + 蔗糖粉）混合製成
  • 以高濃度乙醇液潤濕後填入模型，輕壓成型
  • 乾燥結晶固化，非由壓力促成
  • 代表：Tablet triturates（研製錠）、Hypodermic tablet（皮下用錠）
基本流程：秤量 → 混合 → 造粒 → 乾燥 → 整粒 → 潤滑 → 壓錠 → 包覆 → 檢查 → 包裝
依作用特性分類
釋放機制
  • Immediate release / CT
    未包衣壓製錠，口服迅速溶離
  • Enteric coated (ECT) 腸溶錠
    Delayed release
    胃中不溶，腸道 pH 才釋放
    適用：Pancreatin Aspirin
  • Repeat action (RAT) 重覆作用錠
    速放 + 控釋膜層 + 核蕊藥錠
  • Extended release (XL/ER/SR)
    緩慢釋放，維持血中濃度穩定
    半衰期適合：4–6 hr，TI > 10
  • Delayed action (DAT)
    預期時間才產生藥效，以腸溶機制為代表
  • Effervescent 發泡錠
    酸（檸檬酸：酒石酸 = 1:2）+ 碳酸氫鈉 → CO₂
    不得直接吞服 放置防潮容器
  • RDT 速崩錠（舌上 < 1 min 崩散）
    Zydis 冷凍乾燥技術；加 effervescents 增強速溶
    Loratadine Reditabs Ondansetron ODT
口腔 / 局部作用
  • Sublingual tablet 舌下錠
    舌下迅速吸收，避免首渡效應 & 胃酸
    Nitroglycerin Estradiol
  • Buccal tablet 口頰錠
    置頰側，緩慢溶蝕全身作用
    Nitroglycerin Methyltestosterone
  • Lozenges / Troches 口含錠
    口腔緩慢溶離 ≥ 30 min，局部作用
    壓製法或模製法；以硬糖果為基底
    適用：局部麻醉劑、鎮咳劑
    Cetylpyridinium chloride
  • Chewable tablet 咀嚼錠
    口中嚼碎，多供兒童使用；可不含崩散劑
    稀釋劑：Mannitol、Sorbitol、Xylitol
  • Dental cones 牙科錠
    拔牙後局部抗菌用
  • Gelacaps 明膠著衣錠
    膠囊形狀壓製錠，體積較小
其他給藥途徑
  • Vaginal tablet 陰道錠
    圓形或梨形；壓制法
    稀釋劑：NaHCO₃、乳糖
    Metronidazole
  • Implantation tablet / Pellets 植入錠
    皮下植入，維持 3–6 個月
    ≤ 8 mm 之滅菌錠片
    Estradiol Testosterone
  • Hypodermic tablet (HT) 皮下用錠
    模製錠；完全迅速溶解於水
    須滅菌，加注射水後 SC 給藥
  • Dispensing tablet (DT) 調劑錠
    劇藥調成錠，加蒸餾水溶解使用
    高錳酸鉀 Benzalkonium Cl
  • OROS 滲透幫浦型錠
    零級釋放；半透膜不在腸胃道溶解
    影響因素：表面積、膜厚、雷射孔徑
    不受食物 & 腸胃道 pH 影響
二 賦形劑 Excipients（稀、潤、黏、崩）
稀釋劑 / 填充劑 Diluent / Filler 增加體積、重量
一般用
  • Lactose（乳糖）
    溶解度高、壓錠性好，最常用
    ⚠ 與 Amine 類藥物（鹼性環境）→ Maillard reaction（變色）
  • Microcrystalline cellulose (MCC / Avicel)
    ★ 一人多功能
    同時具稀釋劑、黏合劑、崩散劑；流動性與壓縮性俱佳
  • Starch（澱粉）
    本身兼具崩散與黏合功能；不溶於冷水
  • Dicalcium phosphate (DCP / Di-Tab)
    常用於直打錠
    ⚠ 不可與 Tetracycline 併用（螯合）
  • Calcium phosphate（磷酸鈣）
  • Calcium sulfate dihydrate（二水合硫酸鈣）
    適用：固醇類、維生素錠劑
咀嚼錠專用
  • Mannitol（甘露醇）清涼感、甜味
  • Sorbitol（山梨醇）
  • Xylitol（木糖醇）
直接壓錠專用 (DC Fillers)
  • Spray-dried lactose（噴霧乾燥乳糖）流動性佳
  • Microcrystalline cellulose (MCC) 首選
  • Microcrystals of α-monohydrate lactose
  • Anhydrous lactose（無水乳糖）
  • Pregelatinized starch（預凝膠化澱粉）
  • Crystalline maltose（結晶麥芽糖）
  • Dicalcium phosphate dihydrate (DCP)
  • Sucrose-invert sugar-corn starch mixtures
  • Granule mannitol（顆粒甘露醇）
  • Crystalline sorbitol（結晶山梨醇）
主成分含量通常不超過總重之 20–25%（無 cohesive 性質時）
黏合劑 Binder / Adhesive 促進顆粒形成、增加硬度
水性 Aqueous binders
  • Povidone (PVP)
    最廣用；可溶於水 & 酒精；吸濕性高
  • Starch paste 10–20%
    最常用傳統黏合劑
  • Glucose solution 25–50%
  • Molasses（糖蜜）
  • Gelatin solution 10–20%
    多用於口含錠，溫熱下使用
  • Methylcellulose (MC) 3%
    冷水比熱水好溶
  • Sodium CMC（羧甲基纖維素鈉）
  • Microcrystalline cellulose (MCC)
非水性 Non-aqueous binders（對水敏感藥物）
  • HPMC（Hydroxypropyl methylcellulose）
    先加沸水攪拌（熱水中分散性高）；冷水比熱水好溶
  • PVP（Polyvinylpyrrolidone）
    可溶於水與酒精兩者
  • HPC（Hydroxypropylcellulose）
  • Ethylcellulose (EC)
    水不溶性纖維素；溶於酒精
以酒精或有機媒液配製造粒液，用於濕式造粒
乾粉黏合劑 Dry binders（乾粒法/直打錠）
  • Microcrystalline cellulose (MCC)
  • Acacia powder（阿拉伯膠粉）
  • PVP
  • HPMC
  • Colloidal clays
  • Amylose
明膠三大用途：Binder、Encapsulating Agent、Gelling Agent
崩散劑 Disintegrant 克服黏合強度，促進溶離
一般崩散劑 — 機制分類
機制材料
Swelling 膨脹型
  • Starch（澱粉）
  • Methylcellulose (MC)
  • CMC（Carboxymethylcellulose）
  • Alginic acid（褐藻酸）
  • PVP
  • Cation exchange resins
  • Agar、Kayara、Tragacanth
Capillary 毛細管型
  • Microcrystalline cellulose (MCC)
  • Crospovidone（交聯 PVP）
Super-disintegrants 超級崩散劑
  • Sodium starch glycolate (SSG / Explotab) 用量 5% 膨脹型 Swelling
    修飾型澱粉，強力膨脹
  • Croscarmellose（Cross-linked CMC） 用量 2% 膨脹型 Swelling
    高吸水性、快速作用
  • Crospovidone（Cross-linked PVP） 用量 2–5% 毛細管 Capillary
    親水性；水不溶但利用毛細管崩散
  • Direct compression starch（直打錠專用）
💡 可加 Sodium lauryl sulfate 或 Dioctyl sodium sulfosuccinate（界面活性劑）增進藥物溶解
💡 矯味劑、甜味劑、著色劑、吸附劑均為非必要添加成分
⚠ 咀嚼錠可不含崩散劑；發泡錠用水溶性崩散劑
潤滑劑 Lubricant & 滑動劑 Glidant & 抗黏著劑 Anti-adherent
Lubricant 潤滑劑（0.1–5%）
  • 疏水性（Hydrophobic）
  • Magnesium stearate（硬脂酸鎂）最常用 1%
  • Calcium stearate（硬脂酸鈣）
  • Stearic acid（硬脂酸）
    也具崩散抑制劑功能
  • Talc（滑石粉）
  • Sodium stearyl fumarate
  • 親水性（Hydrophilic）
  • PEG 4000 / 6000（聚乙二醇）
  • Sodium benzoate
  • Sodium lauryl sulfate
⚠ 過量疏水性潤滑劑 → Raincoat effect（雨衣現象）
降低顆粒面對水潤濕性 → 延遲崩散與溶離
改善：加少量界面活性劑
Glidant 助滑劑/滑動劑（改善粉末流動性）
  • Fumed silicon dioxide（氣相 SiO₂ / Aerosil）直打錠最常用
  • Talc（滑石粉）< 5%
  • Corn starch（玉米澱粉）
吸附於顆粒表面，降低顆粒間摩擦力，幫助直壓製錠顆粒流動
Anti-adherent 抗黏著劑
  • 減少顆粒黏附於沖模表面
  • Talc（滑石粉）
  • Corn starch
  • Fumed silicon dioxide
吸附劑 Adsorbent（非必要）
  • Magnesium oxide（氧化鎂）
  • Silicon dioxide (SiO₂)
  • Kaolin、Bentonite、Carbonates
  • 吸附液體成分（共熔混合物、揮發油）；如硝化甘油加 Macrogol 400
★ 多功能賦形劑整理（考試常考）
材料功能
Starch（澱粉） Diluent、Disintegrant、Granulating agent、Anti-adherent；泡成澱粉糊 → Binder
MCC（微晶纖維素） Diluent、Binder、Disintegrant（Glidant）
Croscarmellose（交聯 CMC） Binder、Disintegrant
Gelatin（明膠） Binder、Encapsulating agent、Gelling agent
Stearic acid / 熔點蠟 / 氫化植物油 崩散抑制劑（Dissolution retardant）、Lubricant
Talc Glidant、Lubricant、Anti-adherent
特殊添加物
  • Effervescents 發泡劑：
    Citric acid + Sodium bicarbonate → CO₂（助崩散）
  • Pharmaceutical colorants 著色劑：
    法定水溶性食性色素、Lake dyes（非水溶性）
    光敏感 → 加 1–5% TiO₂（阻光）
  • Flavoring agents 矯味劑：
    甜味劑：Glucose、Mannitol、Saccharin、Sucrose
三 製造製程 Manufacturing Process
濕式造粒 Wet Granulation
1. 秤重→ 2. 研細→ 3. 過篩→ 4. 乾粉混合→ 5. 加黏合劑 → 濕塊→ 6. 造粒（6、8號篩）→ 7. 乾燥（60°C）→ 8. 整粒（12、20號篩）→ 9. 加崩散劑 + 潤滑劑→ 10. 壓錠
  • 黏合劑先溶解於水溶液或酒精，形成造粒液
  • 壓錠最佳細顆粒比：10–20%
  • 適用：對水與熱安定的藥品
優點：適合強效藥、顯色均勻
缺點：步驟繁瑣；不耐熱 / 水藥物不適用
流動床造粒 Fluid Bed Granulation
All-in-one：混合 + 造粒 + 乾燥一次完成
  • 顆粒流動性高；均勻乾燥；耗時短
  • 黏合劑以噴灑方式給予（Acacia 水溶液、Povidone）
噴灑位置與適用
噴灑方式適用
Top-spray（頂噴，逆氣流） Enteric-release、Taste masking
不適合 Sustained release 包衣
Bottom-spray（底噴，Wurster，同氣流） Enteric-release、Sustained release
精密腸溶/長效薄膜衣
Tangential-spray（側噴） Enteric-release、Sustained release、Layering coatings
乾式造粒 Dry Granulation
  • 藥物粉末須具備 cohesive properties
  • 不加液體黏合劑，使用乾粉 binder（MCC、Acacia 乾粉）
方法
  • Slugging（重壓法）
    混合 → 重擊成大錠塊 → 製粒 → 潤滑 → 壓錠（共兩次打錠）
  • Roller compaction（滾壓）
    壓力滾筒擠壓成薄塊 → 破碎過篩 → 製粒
適用：對水或熱敏感之處方成分
缺點：硬度較硬、密度較高，溶離受影響
直接壓錠 Direct Compression (DC)
最簡單；最不影響 BA；無需造粒
  • 不須添加黏合劑；不須加熱
  • 適用：對熱不安定的藥品
  • 主成分一般不超過總重 20–25%
  • 需要 cohesive、流動性好的賦形劑
所需賦形劑特性
  • 稀釋劑：MCC（首選）、Spray-dried lactose、DCP、Pregelatinized starch、Crystalline maltose
  • 崩散劑：Crospovidone、MCC
  • 助滑劑：Fumed silicon dioxide（Colloidal SiO₂）
直接壓錠頂裂（Capping）改善 → 減低入料速度
造粒目的 Purpose of Granulation
  • 使藥物形成可自由流動的顆粒，減少重量差異
  • 提高密度以提供壓縮性
  • 增進黏合性提高硬度，增加含量均一度
四 包衣 Coating 口訣：防底滑（防水層→底衣層→平滑層）
糖衣包覆 Sugar Coating
① Sealing 防水及固封 → ② Subcoating 初包衣（底衣層） → ③ Smoothing 打平滑 → ④ Coating 著色（色素、TiO₂、Fe₂O₃） → ⑤ Polishing 打亮
  • 防水層材料：PVP-stabilized Shellac、CAP、PVAP
  • 底衣層：糖漿黏合 + 撒布劑（CaCO₃、TiO₂、Acacia）
⚠ 體積增加 50–100%；製程最長；不適高劑量藥物
薄膜包衣 Film Coating
成膜材料 Film former
  • HPMC 最常用
  • HPC（Hydroxypropylcellulose）
  • MC（Methylcellulose）
  • PVP（Polyvinylpyrrolidone）
  • EC（Ethylcellulose）親脂性，阻礙藥品釋出
塑化劑 Plasticizer
  • Glycerin（甘油）含烴基
  • Propylene glycol（丙二醇）含烴基
  • PEG（Polyethylene glycol）含烴基
  • Castor oil（蓖麻油）含烴基
  • Triacetin 含羧基
  • Citrate esters 含羧基，常用
  • Diethyl phthalate (DEP)
不透明劑
  • Titanium dioxide (TiO₂)（1–5%）阻光
包覆量佔錠劑總重 2–6%
缺點：有機溶劑具可燃性及汙染性
腸溶包衣 Enteric Coating
胃中不溶 → 腸道 pH 才溶解釋放
  • Shellac（蟲膠）最古老，天然樹脂
  • CAP（Cellulose acetate phthalate）pH > 6 溶解；易水解
  • PVAP（Polyvinyl acetate phthalate）比 CAP 穩定
  • HPMCP 比 CAP 穩定
  • Acrylic copolymers（Eudragit 系列）
    Eudragit L → pH > 6
    Eudragit S / FS → pH > 7（迴腸釋放）
  • Stearic acid、Beeswax — 天然水不溶性材料
  • Methacrylic acid copolymers
phthalate 官能基在酸性環境溶解度差，通過胃後才溶解釋出
微粒包衣 Microencapsulation
  • 目的：解決不良氣味、延長藥物作用
  • 包衣重量：佔總重 2–20%
  • Gelatin（明膠）最常用薄衣材料，最後加甲醛硬化
  • 合成材料：HPMC、HPC、MC、阿拉伯膠、PVA、PVC
  • 若做成 RDTs：顆粒應小到無顆粒感
  • Coacervation（聚集法）：聚合物溶液加入物質使產生相分離
  • 不同溶解度溶媒 / 不同電荷性材料 / 不同 pH 值溶液
  • 微粒散佈腸胃道，增加藥物吸收
  • 需加入塑化劑

缺陷描述原因
Capping（頂裂）錠劑頂部呈蓋狀分開空氣被包埋、細粉太多、壓力過大、入料速度太快

  • 下沖模：高低決定錠劑重量 → 影響厚度、重量、充填量

六 長效劑型 Extended / Controlled Release
適合 vs 不適合長效劑型
適合
  • 半衰期 4–6 hr
  • 治療指數 TI > 10
  • 劑量低
  • 腸胃各部位吸收均一
  • 抗組織胺、NSAIDs
  • Potassium chloride、Propranolol
  • Diltiazem、Ferrous fumarate
不適合
  • 半衰期 ≤ 1/2 hr 或極長
  • 急症藥物
  • 口服吸收不規則
  • 抗生素、肌肉鬆弛劑
  • 毛地黃苷
  • Reserpine
  • 劑量 > 500 mg
長效劑型設計類型
  • Matrix tablet 間質錠
    HPMC 親水性間質：水合後形成凝膠層，緩慢釋出
    不溶性塑性基質：擴散釋放，隨糞便排出
  • OROS 滲透幫浦型
    零級釋放；不受食物及 pH 影響
    滲透壓劑：MgCl₂、CaCl₂、NaCl、KCl、MgSO₄
  • Ion-exchange resin tablet
    藥物釋放取決於腸胃道 pH 及電解質濃度
  • Coated bead / Pellet tablet
    MCC、EC、Glyceryl monostearate、Cetyl alcohol
  • Compression coating
    適用對濕氣不穩定藥品；均一度較好
  • Microencapsulation tablet
Extended-release vs Delayed-release 比較
項目
Extended-release (XL/ER/SR)
Delayed-release (DR/腸溶)
釋放特性
部分速放 + 部分緩速；0 級釋放

目的

避免被胃酸破壞；減少胃部刺激
膜衣材料
Acrylic resins、Shellac、EC
Shellac、Methacrylic acid copolymer B
備註
0 級釋放 ≠ 0 級吸收
酸性藥物→降低胃刺激；鹼性藥物→避免胃酸破壞
BCS & IVIVC 重點
  • BCS：依溶解度和穿透度分 4 級，預測藥物物化性質與 BA 的關係
  • IVIVC：體外溶離試驗預測體內藥物吸收；BCS II → Extended-release / Controlled-release 劑型
  • 長效劑型不可剝半或磨粉
  • 口服緩釋錠兩大類：間質錠 Matrix 與 儲藏式 Reservoir
七 考試重點整理 Key Points
配伍禁忌 / 注意事項
  • Lactose + Amine 類（鹼性） → Maillard reaction（變色）
  • DCP + Tetracycline → 螯合，影響吸收；不可併用
  • Mg stearate 過量 → Raincoat effect（雨衣現象）
    改善：加界面活性劑
  • 低水溶性 / 疏水性主成分 → 選用水溶性稀釋劑以提高 BA
  • 澱粉不溶於冷水；MC、HPMC 冷水比熱水好溶
  • HPMC 先加沸水攪拌，冷卻後形成均勻膜
  • Gelatin 溶液需溫熱下使用（冷卻凝固）
考試常考重點
  • 直接壓錠最不影響 BA：首選 MCC，其次 Spray-dried lactose、DCP
  • 超級崩散劑：SSG 5%、Croscarmellose 2%、Crospovidone 2–5%
  • SSG = Sodium starch glycolate = Explotab；膨脹型
  • Crospovidone = 毛細管型；水不溶但親水
  • Flow meter 比安息角更具實用參考價值
  • 壓錠普通壓力：3000–4000 磅（1360–1820 kg）
  • 脆度試驗：25±1 rpm，100 轉，4 min，過 16 號篩
  • 糖衣口訣：防底滑（防水層→底衣層→平滑層→著色→打亮）
  • Wurster Process = Bottom-spray = 適合腸溶 & 持續釋放
  • Top-spray 不適合 Sustained release 包衣
  • RDT：Zydis 冷凍乾燥技術；含明膠、糖、水溶性賦形劑
  • CaSO₄、Ca₃(PO₄)₂ 適用固醇類 / 維生素錠劑
粉末分離 Segregation 預防
  • 原因：顆粒尺寸、密度、外形、彈性係數不同
  • 靜置時：密度影響最大
  • 攪拌時：密度影響最小
  • 預防：減少運送步驟次數與落差、粉塵控制、緩慢充填速率
  • 使用偏轉器（deflector）、藥輪（vane）、分布器（distributor）
  • 適當通風、適當漏斗設計
