01術語定義

Immediate Release 原態釋放

未做任何修飾，依原來狀態釋放。吃下去→崩散→溶離，無特殊設計。

Modified-Release 修飾釋放

藥物釋放的速率或時間與原態釋放不同。大多為錠劑或膠囊，也有眼用、注射、皮下、陰道製劑及經皮貼片。常見為延釋(ER)與遲釋(Delayed-release)。

02延釋理論基礎

傳統劑型一天需服多次，血中濃度有波峰波谷：波谷落到MEC以下→失效；波峰超過MTC以上→副作用。Extended-release目的是讓血中濃度平穩維持在治療窗內。

✅ 優點

  • 血中濃度波動少，較少副作用
  • 減少給藥次數（一天1~2次）
  • 增加便利性與服藥依順性
  • 降低健康照顧成本
  • 維持有效治療濃度時間延長

❌ 缺點

  • 劑量調整彈性差：不能磨粉、壓碎、拆開膠囊→破壞設計
  • Dose Dumping 劑量傾釋：製備不良時，一天份量一次全釋出→血中濃度過高→嚴重風險
  • 製備成本較高
  • 不同廠牌間生體可用率可能不同，不可任意替換
典型設計：部分劑量立即釋出（loading dose）+ 部分劑量緩速釋出，讓血中濃度快速到達治療範圍後持續維持。

臨床使用注意事項

  • 不能壓碎錠片/圓粒給幼兒使用
  • 不能使用作為調配成其他劑型
  • 不能與速放劑型交替使用（生體可用率不同）
  • 需告知病人會排出劑型空殼（正常現象，尤其osmotic pump）
  • 在穩定狀態後不能與速放製劑交替（Cmax不同）

條件適合不適合 / 不需要

單劑量 不適合太大 單劑量過大→錠劑體積大→難吞嚥

適合/不適合的例子

✅ 適合做 ER

Aspirin：慢性止痛、抗凝
Ferrous Fumarate：鐵劑，治慢性貧血
Morphine Sulfate：慢性癌痛

❌ 不適合做 ER

Ampicillin：吸收不均、半衰期短
Penicillin G：不穩定，腸道吸收差
Furosemide：吸收差且需快速作用（急性）
Levodopa：吸收速率變化大（不均一吸收）

T1Coated Beads / Granules / Microspheres 包衣小珠

將藥品包覆在小珠上（或以小珠為核），外包不同厚度的障壁性包衣，厚度不同→釋放時間不同→3~4種組合→裝成一顆膠囊。直徑約1mm，一個劑量單位>100個小珠。

製備方式（依藥物劑量）

藥物劑量小

藥品噴在惰性核心上：

  • Nonpareil seeds（sugar/starch糖珠，425~850μm）
  • MCC小球（170~600μm）

再噴上包衣層控制釋放速率

藥物劑量大

藥品可直接成型為小球，再噴上包衣層即可

包衣材料（考試核心）

適合的水難溶性包衣材料

Beeswax 蜂蠟 Carnauba Wax 棕櫚蠟 Glyceryl Monostearate Cetyl Alcohol Ethylcellulose (EC)

水性EC膜衣系統：Aquacoat®（FMC）、Surelease®（Colorcon）

HPMC（Hydroxypropyl Methylcellulose）水溶性→最不適合作為 coated beads 包覆材料！（108、113年各考一次）
Glyceryl monostearate 也有非離子型介面活性，但熔點較高（軟膏章節也有出現）；Cetyl Alcohol 也是蠟質特性，熔點高→可當硬化劑。
市售例：Spansule capsule（典型coated beads膠囊設計）

T2Multitablet System 多錠片系統

多個球形小錠片（直徑3~4mm），8~10顆裝入一個明膠膠囊。

  • 部分小錠片未包衣→立即釋放
  • 部分小錠片包衣→延長釋放
  • 可分隔不可配伍的成分（打成不同小錠再裝膠囊，避免接觸）
因需要特殊微小punch/die，製備精度高，市面上較少見，現多被其他劑型取代。

T3Microencapsulated Drug 微粒膠囊包衣

Microspheres

中間是固體（實心），藥品分散在基質中

Microcapsules

中間是液體或氣體，有明顯的 wall material 包覆核心。課本所指的 microencapsulation 多指此類。

歷史背景

1930年代：為了找碳紙的替代品，把染料包成微粒塗在紙上，筆尖壓力破膜→染料釋出，但手掌面積大→壓力不足→不破→乾淨。後來此原理應用於藥品。

包覆材料

Gelatin 明膠（最常用天然材料） Polyvinyl Alcohol (PVA) Ethylcellulose Polyvinyl Chloride
Lactose 乳糖是水溶性的，會自己溶解→最不適合作包覆材料。

Coacervation 共聚/凝聚

Simple Coacervation 簡單共聚

一種polymer，降低自身溶解度→沉澱析出→包覆藥品

引發方式：

  • 添加 non-solvent（如加酒精→降低水溶性）
  • 添加 inorganic salts（鹽析效果）
  • 改變溫度

Complex Coacervation 複合共聚

兩種相反電荷的親水 polymers，互相中和→共聚沉澱→包覆藥品

最常見：帶正電 Gelatin Type A + 帶負電 Acacia（阿拉伯膠）

以 Glutaraldehyde 或 Formaldehyde 交聯硬化→收縮成硬球

不可用來引發相分離的：不同分子量的膠體（B）。不同分子量≠不同溶解度，無法造成相分離。（1091考題）

調整釋放速率

  • 改變核心藥物：wall polymer 比例（wall polymer 通常佔 2~20%）
  • 改變包衣聚合物種類
  • 改變微膠囊化方法

優點

  • 口服後顆粒散布整個胃腸道→大面積→增進吸收
  • 可遮蔽藥品苦味
市售例：Micro-K Extencaps（KCl，Wyeth）。名稱解碼：Micro=微粒、K=KCl、Extencap=extended capsule

T4Hydrophilic Matrix System 親水性間質系統

藥物與緩慢溶蝕的親水性賦形劑混合造粒後壓錠，是最接近傳統錠劑製備的ER技術。

主要控釋材質（考試核心）

HPMC（Hydroxypropyl Methylcellulose / Hypromellose）
  • 用量 >20% 才能產生滿意的凝膠化控釋效果
  • 用量少→黏合劑；用量多→凝膠化控釋
  • HPMC完全分散在配方中，以濕粒法或滾壓法（乾粒法）造粒，再壓製成錠

釋放機轉（雙重）

接觸胃液
→
HPMC水合
→
表面形成凝膠層
→
藥物擴散出凝膠層
→
外層持續溶蝕
→
內部水分繼續滲透→更多藥物釋放

水溶性藥物

主要靠 Diffusion 擴散：溶解在凝膠層的水性通道中緩慢擴散出去

水不溶性藥物

主要靠 Erosion 溶蝕：等外層凝膠溶蝕後暴露出藥物再釋出

可製備的劑型

  • 單層錠：全部含HPMC→完整延長釋放
  • 雙層/三層錠：一層不含HPMC（立即釋放）+ 一層含HPMC（延長釋放）
  • 內外核心錠：外層速放，內核延放
  • HBS膠囊（Hydrodynamically Balanced System）：見下方
HBS系統特殊設計

膠囊內含HPMC粉末/顆粒。吃下去到胃→水分進入→HPMC水合→膠囊殼溶解後維持凝膠狀plug→密度低→浮在胃液上→不隨蠕動快速排出→延長胃部停留時間→適合主要在小腸上段吸收的藥物。

HBS膠囊（如 Madopar® HBS）不可打開膠囊服用！拆開後無法形成凝膠plug，失去緩釋效果。主成分：Levodopa（主要吸收在小腸上段）
不需加塑化劑（塑化劑是給膠囊殼用的，打錠不需要）。市售例：Oramorph SR tablets（morphine sulfate，AllPharma）

T5Inert Plastic Matrix System 惰性塑膠間質

藥物與水不溶性惰性材料混合造粒壓錠。間質本身不溶解、保持原形隨糞便排出。

常用惰性材料

Polyethylene (PE) Polyvinyl Acetate（PVAc，非水溶性） Polymethacrylate（Eudragit®）

注意：Polyvinyl Alcohol (PVA) 是水溶性的（當增稠劑、眼藥水用），Polyvinyl Acetate (PVAc) 才是水不溶性

釋放機轉：擴散（Diffusion）

水分從縫隙進入
→
形成水性通道
→
藥品溶於水中
→
從通道擴散出去

水溶性藥物

可溶於水性通道→擴散效果佳

水不溶性藥物

難溶於水性通道→釋放效率較差，不太適合此系統

錠劑空殼從糞便排出屬正常現象，不代表藥物未吸收。市售例：Gradumet（Abbott，Ferrous Sulphate，Eudragit® 為控釋材質）
製備方式（造粒→壓錠）與傳統錠劑製備最接近，差異最小（1061考點）。

T6Complex Formation 複合物形成

藥物與化學物質結合形成複合物（complex），依環境pH緩慢溶解→藥物慢慢解離→產生藥效。

最常用材質（考試核心）

Tannic Acid 鞣酸（單寧酸）

為何最常用（三大優勢）：

  • 有大量 OH 基→與帶正電藥品結合更穩固
  • 天然來源（植物中提取）→安全性高、毒性低
  • 有收斂效果→可緩解鹼性藥品對胃腸道的刺激

常搭配帶正電（鹼性）藥品使用，形成 tannate salt，依體液pH緩慢解離。

市售例：Rynatan（Wallace）：chlorpheniramine tannate + phenylephrine tannate。名稱中 "-tan" 即 tannic acid 的暗示。

T7Ion-Exchange Resins 離子交換樹脂

藥物先與離子交換樹脂（insoluble resin，不可溶）結合形成複合物，到體內需先進行離子交換才能釋放藥物。

陽離子性藥物（帶正電）

→ 接在 陰離子交換樹脂（帶負電，如SO₃⁻）

→ 胃（酸性）中H⁺多 → H⁺取代藥物 → 藥物釋出

→ 胃部釋出 > 小腸

陰離子性藥物（帶負電）

→ 接在 陽離子交換樹脂（帶正電）

→ 腸（鹼性）中負離子多 → 負離子取代藥物 → 藥物釋出

→ 小腸釋出 > 胃部

常見混淆點：
· 使用不可溶性樹脂（insoluble resin）
· 陰離子樹脂（anionic resin）吸附帶正電藥物（不是帶負電）
· 藥物釋放速率取決於pH和電解質濃度，不是藥物溶解度
· 受食物及各營養成分影響（離子會競爭交換）

進階版：包衣離子交換樹脂

Polymer Barrier Coating + Bead Technology

在樹脂-藥物複合物外再包一層polymer barrier（如乙基纖維素）。需完成兩個步驟才釋藥：

離子交換釋出藥物
→
藥物再穿透包衣層擴散
→
產生藥效

可延長藥效至12小時。包含藥物的聚合物顆粒夠小，可以懸浮→同時製備液體劑型（緩釋懸浮劑）。

市售例：Ionamin capsules（phentermine resin）；Tussionex Pennkinetic（hydrocodone polistirex + chlorpheniramine polistirex 懸浮劑）
離子交換樹脂可遮蔽藥品苦味（樹脂把藥品接住，舌頭感覺不到苦味）—此為1032年考點。

T8Osmotic Pump 滲透壓幫浦

以滲透壓梯度（非濃度梯度）為驅動力，將藥物定速推出。

最常用半透膜材質（考試核心）

Cellulose Acetate 醋酸纖維素

半透膜：水分可穿過，藥品不能穿過→藥品只能從雷射打的小孔出去

EOP vs PPOP 比較

EOP：Elementary Osmotic Pump 簡單型

  • 核心：單層（藥物 + 滲透壓劑混合）
  • 外覆半透膜，雷射打孔（直徑0.4mm）
  • 水進入→溶解滲透壓劑→產生壓力→推藥液從孔釋出
  • 適用：水溶性藥物（水不溶者難推出）
  • 後期滲透壓劑減少→推力變弱→釋放速率可能不穩定

PPOP：Push-Pull Osmotic Pump 推拉型

  • 核心：雙層（藥物層 + 推進層），中間有彈性膜隔開
  • 水進入→推進層吸水膨脹→推擠藥物層→藥物從孔釋出
  • 可釋放水不溶性藥物（懸浮態也能被推出）
  • 推進層始終存在→推力恆定→Zero-order 釋放
  • 市售：OROS system (Alza)、Procardia XL、Glucotrol XL

常用滲透壓劑（Osmotic Agents）

產生滲透壓：π = MRT，需高分子量的水溶性高分子

Methylcellulose (MC) HPMC Sodium CMC PVP Carbopol Polyethylene Oxide (PEO，大分子量PEG)

釋放速率影響因素

✅ 會影響

  • 膜的表面積
  • 膜的厚度（最易影響★）
  • 膜的組成
  • 輸送孔的直徑
  • 滲透壓梯度大小

❌ 不影響（重要考點）

  • 胃腸道 pH 值
  • 進食狀態（食物）
  • 胃腸蠕動度
  • 媒液pH值（體外溶離試驗也無關）

COER 系統（進階版 Osmotic）

Covera-HS（Verapamil HCl）：服藥後4~5小時才開始釋放

用途：治療清晨高血壓，睡前服用，清晨才發揮藥效。

吞服
→
水穿入半透膜
→
Delay Coat緩慢溶解（~4-5hr）
→
水繼續進入
→
Push Layer擴張
→
藥物由micropore定速釋放
延遲機制：核心與半透膜之間加了緩慢溶解包衣層（delay coat）（1102考點：答案D）
惰性殼（生物惰性成分）在胃腸道保持完整，從糞便排出不代表藥物沒有吸收！（Adalat OROS®、Glucotrol XL 都會排殼）

T9Repeat Action Tablets 重複作用錠

含兩個劑量，一個立即釋放（外層），另一個延遲釋放（內核），兩者以控釋膜層隔開。

結構（考點）

速放藥層（外殼）
+
控釋膜層（barrier coat）
+
核蕊藥錠（4~6小時後釋放）
市售例：Clarinase Repetabs®（外層：pseudoephedrine + loratadine立即釋放；內核：pseudoephedrine延遲釋放。loratadine半衰期長，不需放內核）；Proventil Repetabs®（albuterol）
Repetabs 的 "-tab" 暗示是錠劑，"Repe-" 暗示 repeat action。
