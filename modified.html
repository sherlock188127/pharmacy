01術語定義

Immediate Release 原態釋放

未做任何修飾，依原來狀態釋放。無特殊設計，吃下去即崩散→溶離。

Modified-Release 修飾釋放

藥物釋放的速率或時間與原態釋放不同。大多為錠劑或膠囊，也有眼用、注射、皮下、陰道製劑及經皮貼片。

術語 英文 定義重點
延釋 Extended-Release (ER) FDA定義：可減少傳統劑型給藥次數；以控制方式於預定速率、期間、位置釋放
遲釋 Delayed-Release 非立即釋放，在特定時間（時間基礎或pH基礎）釋放；多為腸衣錠/膠囊
重複作用 Repeat Action 含兩個劑量：一個立即釋放，第二個延遲釋放（如 bilayered tablets）
標靶釋放 Targeted Release 釋放集中於特定身體部位、組織或吸收位置
控速遞藥 Rate-Controlled Delivery 遞藥速率由裝置特性控制，而非由生理或環境因素（pH、蠕動）控制
SR、CR、TR、SA、PA、LA 等術語與 Extended-Release 常互換使用，多用於描述口服給藥劑型，在不同教科書間可能有些微差異。

02延釋理論基礎

✅ 優點

  • 血中濃度波動少，較少副作用
  • 減少給藥次數（一天1~2次）
  • 增加便利性與服藥依順性
  • 降低健康照顧成本

❌ 缺點

  • 劑量調整彈性差：不能磨粉、壓碎或拆開膠囊
  • Dose Dumping 劑量傾釋：製備不良時，24小時份量一次全部釋出→血中濃度過高→嚴重風險
典型設計：部分劑量速放釋出（loading dose）+ 部分劑量緩速釋出，讓血中濃度快速到達治療範圍後持續維持。

T1Coated Beads / Granules / Microspheres

包衣小珠、顆粒或微粒小球。利用傳統包衣缽或空氣懸浮包衣法製備。

製備方式

藥物劑量小

藥品噴在 sugar/starch 糖珠 (nonpareil seeds, 425–850 μm) 或 MCC 小球 (170–600 μm) 表面，再噴包衣層。

藥物劑量大

藥品可自行形成圓球，直接噴上包衣層。

包衣材料（考試重點）

適合的包衣材料（水難溶性）
Beeswax 蜂蠟 Carnauba Wax 棕櫚蠟 Glyceryl Monostearate Cetyl Alcohol Ethylcellulose (EC) Aquacoat® / Surelease® (EC水性膜衣系統)
HPMC（Hydroxypropyl Methylcellulose）是水溶性的，最不適合作為 coated beads 的包覆材料！（考過2次：108、113年）
典型直徑約 1 mm；一個劑量單位約 100 個以上；有 3~4 種釋放組合（不同包衣厚度→不同釋放時間）。市售例：Spansule capsule

T2Multitablet System 多錠片系統

多個球形小錠片（直徑 3–4 mm），裝入一個明膠膠囊（8–10 個 minitablets）。

  • 部分小錠片：未包衣 → 立即釋放
  • 部分小錠片：包衣 → 延長釋放
  • 可分離不可配伍的成分，避免接觸
因打錠工具（punch/die）要求精密，市面上較少見，現多被其他劑型取代。

T3Microencapsulated Drug 微粒膠囊包衣

Microspheres vs Microcapsules

Microspheres

中間是固體（實心），藥品分散在基質中

Microcapsules

中間是液體或氣體，有明顯的 wall material 包覆核心

包覆材料

Gelatin 明膠（最常用天然材料） Polyvinyl Alcohol (PVA) Ethylcellulose Polyvinyl Chloride
Lactose 乳糖是水溶性的，最不適合作為包覆材料。

Coacervation 共聚/凝聚

Simple Coacervation

一種 polymer，藉由降低溶解度沉澱析出。方法：

  • 添加 non-solvent（如酒精）
  • 添加 inorganic salts（鹽析）
  • 改變溫度

Complex Coacervation

兩種相反電荷的親水 polymers（例：帶正電 Gelatin Type A + 帶負電 Acacia），電荷被中和→凝聚→包覆藥品。以 Glutaraldehyde 或 Formaldehyde 交聯硬化。

不可用來引發相分離的是：不同分子量的膠體（B）。不同分子量≠不同溶解度。（1091考題）

調整釋放速率的方法

  • 改變核心藥物：wall polymer 比例（wall polymer 通常佔 2~20%）
  • 改變包衣聚合物種類
  • 改變微膠囊化方法
優點：口服後顆粒散布在腸胃道形成大面積，增進吸收。市售例：Micro-K Extencaps（KCl）

T4Hydrophilic Matrix System 親水性間質系統

藥物與緩慢溶蝕的親水性賦形劑混合造粒再壓錠。

主要控釋材質（考試核心）
HPMC (Hydroxypropyl Methylcellulose / Hypromellose)

HPMC > 20% 可產生滿意的釋放速率。量少→黏合劑；量多→凝膠化控釋。

市售例

Oramorph SR tablets（morphine sulfate）

Madopar® HBS（Levodopa）→ HBS系統，凝膠狀plug浮於液面，延長胃部停留時間

製備特色

可製備成單層、雙層、三層或內外核心錠，以及延長釋放膠囊（HBS系統）。不需加塑化劑。

HBS 膠囊（如 Madopar® HBS）不可打開膠囊服用，否則無法維持凝膠plug形狀，失去緩釋效果。

T5Inert Plastic Matrix System 惰性塑膠間質

藥物與水不溶性惰性材料混合造粒壓錠。

常用惰性材料
Polyethylene (PE) Polyvinyl Acetate Polymethacrylate (Eudragit®)

釋放機轉

擴散（Diffusion）為主。水分從縫隙進入形成水性通道，藥品從通道擴散釋出。矩陣本身不溶解，隨糞便排出。

注意

水不溶性藥物用此系統釋放效率較差（靠擴散，藥品不溶→難釋出）。排便可見錠片空殼，屬正常現象。

市售例：Gradumet（Ferrous Sulphate, Abbott）；Eudragit® 作為控釋材質。
這種劑型製備方式（造粒→壓錠）與傳統錠劑製備最接近，差異最小。（1061考題）

T6Complex Formation 複合物形成

藥物與化學物質結合形成複合物 complex，依環境 pH 緩慢溶解釋放。

最常用材質（考試重點）
Tannic Acid（鞣酸）

優勢：① 多個 OH 基 → 與帶正電藥品結合更穩固；② 天然來源，安全性高；③ 有收斂效果，可緩解某些鹼性藥品對胃腸道的刺激。

市售例：Rynatan（chlorpheniramine + phenylephrine tannate）

T7Ion-Exchange Resins 離子交換樹脂

陽離子性藥物（帶正電）

接於陰離子交換樹脂（帶負電，如 SO₃⁻）。在胃（酸性）→ H⁺ 濃度高 → 離子交換→ 藥物釋出。胃 > 腸

陰離子性藥物（帶負電）

接於陽離子交換樹脂（帶正電）。在腸（鹼性）→ 負離子多 → 離子交換→ 藥物釋出。腸 > 胃

進階版：包衣離子交換樹脂

在樹脂-藥物複合物外再加 polymer barrier coating（如乙基纖維素），需完成兩個步驟才能釋藥：①離子交換 + ②擴散穿過包衣層 → 延長藥效至 12 小時。

可遮蔽藥品苦味（C選項考點：1032年）。市售例：Tussionex Pennkinetic（hydrocodone + chlorpheniramine polistirex）
重要觀念：
· 使用不可溶性樹脂（不是可溶性）
· 帶負電樹脂（anionic resin）吸附帶正電藥物（不是負電）
· 腸胃道中受食物、電解質、pH 影響
· 藥物釋放速率取決於離子交換環境（pH、電解質濃度），而非藥物溶解度

T8Osmotic Pump 滲透壓幫浦

最常用半透膜材質
Cellulose Acetate (醋酸纖維素)

EOP：Elementary Osmotic Pump（簡單型）

  • 核心：藥物 + 滲透壓劑，外覆半透膜，雷射打孔 (0.4 mm)
  • 水進入→溶解滲透壓劑→產生滲透壓→推藥液從小孔釋出
  • 適用：水溶性藥物（水不溶者推出困難）
  • 釋放遵循 Zero-order（零級動力學）

PPOP：Push-Pull Osmotic Pump（推拉型）

  • 核心分兩層：藥物層 + 推進層（高分子滲透劑）
  • 水進入→推進層膨脹→推擠藥物層→藥物從孔釋出
  • 可釋放水不溶性藥物（懸浮態也能推出）
  • 市售例：OROS system (Alza) / Procardia XL (nifedipine) / Glucotrol XL (glipizide)

釋放速率影響因素

✅ 會影響

  • 膜的表面積
  • 膜的厚度（最易影響）
  • 膜的組成
  • 輸送孔的直徑

❌ 不影響

  • 胃腸道 pH 值
  • 進食狀態
  • 胃腸蠕動度
惰性殼（生物惰性成分）在胃腸道保持完整，從糞便排出不會被人體吸收，不代表藥物沒有吸收！

DRDelayed-Release 遲釋口服劑型

藥物延遲至小腸才釋放，主要機轉為腸溶包衣（Enteric Coating）。

設計目的

保護藥物

避免被胃酸破壞：Erythromycin、Omeprazole (PPI)

保護胃

減少藥物對胃的刺激：Aspirin、KCl、Doxycycline

最佳吸收/局部治療

藥物在小腸有較好吸收或治療腸道疾病：Mesalamine（治潰瘍性大腸炎，用 Eudragit S pH≥7 溶解）

腸溶包衣材料

材料特性溶解pH
Shellac 蟲膠 天然材料，腸溶性 pH >7
Cellulose Acetate Phthalate (CAP) 最常用合成腸溶材料 pH ~6
Polyvinyl Acetate Phthalate (PVAP) 合成腸溶材料 pH >5
HPMCP HPMC + phthalate pH ~5–6
Eudragit S (Methacrylic acid copolymer B) 溶於迴腸（ileum）以下 pH ≥7
HPMC（Hydroxypropyl Methylcellulose）是水溶性的，最不適合作為腸溶包衣材料！

IVCIVIVC：體外-體內相關性

In Vitro–In Vivo Correlation：比較體外溶離試驗與體內血中濃度的相關性，節省臨床試驗時間與成本。

Level比較對象說明實用性
Level A 全部體外溶離曲線 ↔ 全部體內吸收曲線（點對點關係） 最常提交；信息量最大；最有預測價值 最高
Level B 平均體外溶離時間 ↔ 平均體內溶離時間 or 平均體內滯留時間
體外溶離速率常數 ↔ 吸收速率常數		 特性總結參數之間的關係 中等
Level C 體外特定時間溶離量（如 T50）↔ 體內特定參數（Cmax 或 AUC） 單一點對點；在配方開發早期有用；無法反映曲線完整形狀 最低

IVIVC 建立條件（FDA 指引）

  • 溶離裝置：USP Type I（網籃）or Type II（槳式） 為優先
  • 溶離液 pH：不超過 6.8 的水性媒液（難溶藥物可加 1% SLS）
  • 每批至少測 12 粒個別劑量單位
  • 受試者：空腹狀態；6~36 名
  • 研究設計：交叉研究最佳

QA重要歷屆考題

口服控釋製劑，下列何者錯誤？
113-2 ▼
  • A. 體內半衰期4~6小時之內的藥品，適合製備成控釋劑型
  • B. Ion-exchange resins 之藥物釋放速率通常取決於藥物溶解度
  • C. Osmotic pump 之藥物溶液通透半透膜的速率和媒液pH值無關
  • D. Microencapsulation 可以利用包衣與核心之重量比來調控藥物釋放速率
顯示詳解
離子交換樹脂藥物釋放取決於胃腸道pH值與電解質濃度（離子交換環境），不是取決於藥物溶解度。

107-1 ▼
  • A. 速放型（Immediate-Release）
  • B. 長效型（Extended-Release）
  • C. 腸溶型（Enteric-Release）

比較 EOP 和 PPOP 二種滲透壓控釋系統，下列敘述何者錯誤？
110-2 ▼
  • A. PPOP 比 EOP 多了一層吸水膨脹的高分子層，使藥物能遵循 first order kinetics 釋放
  • B. 在 PPOP 系統，藥物層及高分子層均會加入 osmotic agents
  • C. 和 EOP 相比，PPOP 提高了水溶性不佳藥物的遞送效率
  • D. 在 PPOP 系統，不論是溶解狀態或懸浮的藥物均可自此系統釋放
顯示詳解
PPOP 系統藥物釋放遵循 Zero-order（零級）動力學，而非 First-order（一級）。驅動力是固定的滲透壓梯度，與藥物濃度無關，故為零級動力學。

下列何者屬於 Level A 的 IVIVC？
112-1 ▼
  • A. 體外溶離速率常數和體內吸收速率常數
  • B. 體外溶出 50% 的時間和體內最高血中濃度
  • C. 體外平均溶離時間和體內平均溶離時間
  • D. 體外溶離量和體內吸收量之經時變化相關性
顯示詳解
Level A = 點對點（point-to-point）關係，是全部體外溶離時程 vs 全部體內吸收時程的比較，信息量最大，預測性最高。
Level B = 平均時間對平均時間（總結參數）。Level C = 某時間點溶離量 vs Cmax 或 AUC。
