01術語定義

Immediate Release 原態釋放

未做任何修飾，依原來狀態釋放。無特殊設計，吃下去即崩散→溶離。現在中華藥典翻成「原態釋放」，意即依照原來的狀態，沒有進行任何修飾。

Modified-Release 修飾釋放

藥物釋放的速率或時間與原態釋放不同。大多為錠劑或膠囊，也有眼用、注射、皮下、陰道製劑及經皮貼片。常見為延釋（extended release）與遲釋（delayed release）。

術語英文定義重點備註
延釋 Extended-Release (ER) FDA定義：可減少傳統劑型給藥次數；以控制方式於預定速率、期間、位置釋放藥物，達並維持最適宜治療血中濃度 多用於描述口服給藥劑型
遲釋 Delayed-Release 非給藥後立即釋放，在某特定時間釋放（時間基礎或環境pH基礎）；多為腸衣錠或腸衣膠囊 腸溶製劑最具代表性
持續釋放 Sustained-Release (SR) 這些術語意義與 Extended-Release 大多相同，在不同教科書或文獻間常互換使用 ≈ ER

02延釋理論基礎

傳統劑型一天要吃二三四次，血中濃度有波峰（可能超過MTC→副作用）與波谷（落到MEC以下→失效）的波動。Extended-release的目的是讓血中濃度以平穩的方式持續在治療窗內。

大部分ER設計會加上loading dose（立即釋放部分），讓血中濃度快速達到治療效果，再搭配緩速釋放部分撐久一點。

✅ 優點

  • 藥物血中濃度較少波動→較少不良副作用
  • 減少給藥次數（一天1~2次）
  • 增加便利性與服藥依從性
  • 延長病人維持有效濃度的期間
  • 降低健康照顧成本

❌ 缺點

  • 劑量調整彈性差：不能磨粉、壓碎、拆開膠囊→破壞設計→無法調整劑量
  • Dose Dumping 劑量傾釋：製備技術失敗時，本來應24小時緩慢釋放的劑量一次全部釋出→血中濃度過高→嚴重風險

臨床使用注意事項

  • 不能壓碎錠片/圓粒給幼兒使用（破壞控釋設計）
  • 不能使用作為調配成其他劑型
  • 不能與一般速放劑型交替使用（兩者Cmax、生體可用率不同）
  • 需告知病人會排出劑型空殼（正常現象，尤其osmotic pump系統）
  • 不同廠牌控釋製劑間因生體可用率可能不同，不可任意替換使用

T1Coated Beads / Granules / Microspheres 包衣小珠

利用傳統包衣缽或空氣懸浮包衣法製得。典型包衣小珠直徑約1mm，一個劑量單位100個以上，有3~4種釋放組合（包衣厚度不同→釋放時間不同→裝成同一顆膠囊）。

製備方式（依藥物劑量選擇）

藥物劑量小

藥品噴在惰性核心表面，再噴包衣層。惰性核心選擇：

  • Nonpareil seeds / Inert beads（sugar/starch製成的糖珠，425~850μm）
  • MCC小球（microcrystalline cellulose，170~600μm）

藥物劑量大

藥品本身可以成型為圓球，直接噴上包衣層即可，不需要額外的惰性核心。

包衣材料

一部分顆粒不包衣（提供立即釋放），另一部分（約2/3~3/4）包不同程度的脂質或纖維素材料，達到延長釋放。

適合的包衣材料（水難溶性）

Beeswax 蜂蠟 Carnauba Wax 棕櫚蠟 Glyceryl Monostearate Cetyl Alcohol Ethylcellulose (EC)

水性EC膜衣系統（水不溶性EC加塑化劑）：Aquacoat®（FMC公司）、Surelease®（Colorcon公司）

Glyceryl monostearate：也是非離子型介面活性劑（有親水端和親油端），但介面活性不強，熔點較高，在軟膏章節也有當硬化劑使用。
Cetyl Alcohol（鯨蠟醇）：熔點高，有類似蠟質特性，在軟膏章節也作為硬化劑增加黏稠度與硬度。

HPMC（Hydroxypropyl Methylcellulose）是水溶性的，最不適合作為 coated beads 的包覆材料！此題考過兩次（108-1、113-2），是高頻考點。
市售例：Spansule capsule（典型coated beads膠囊設計，名稱中 span = sustained，sule = capsule）

T2Multitablet System 多錠片系統

製備多個球形微小錠片（直徑3~4mm），8~10顆裝入一個明膠膠囊。

  • 部分小錠片未包衣→立即釋放
  • 部分小錠片包衣→延長釋放
  • 優點：可分隔不可配伍的成分（打成不同小錠再裝膠囊，避免接觸）
因為錠片非常小（3~4mm），需要特殊尺寸的punch和die，製備精度要求高，市面上比較少見，現多被其他劑型取代。

T3Microencapsulated Drug 微粒膠囊包衣

Microencapsulation 是將固體、液體甚至氣體，透過在被包覆物質周圍形成薄膜（wall material）的方式包成微粒大小的顆粒。

Microspheres（微粒小球）

中間是固體（實心），藥品分散在基質中。

Microcapsules（微粒膠囊）

中間是液體（或氣體），有明顯的 wall material 包覆核心。課本所指的 microencapsulation 以此為主。

歷史背景

1930年代：為了找碳紙（carbon paper）與碳帶的較乾淨替代品，把染料（dye）包成微粒，塗在紙的一面。

1950年代：出現複寫紙，含有裝著染料的微小明膠膠囊。機制：筆尖的集中壓力→破膜→染料釋出→覆印上去；手掌面積大→壓力分散→不足以破膜→手不會髒。

後續發現 microencapsulation 的原理可以應用在藥品，讓藥品比較慢地釋放出來。

包覆材料

Gelatin 明膠（最常用天然材料） Polyvinyl Alcohol (PVA) Ethylcellulose (EC) Polyvinyl Chloride (PVC)

包衣材質通常佔整個微粒重量的 2~20%（太薄→效果差；太厚→微粒太大）。

Lactose（乳糖）：是甜味水溶性填料，常用作稀釋劑，但本身遇水即溶，無法形成穩定的包覆膜→最不適合作為包覆材料。

Coacervation 共聚/凝聚

Coacervation 指的是包衣材質聚在一起，把藥品包覆起來的過程，分為兩種：

Simple Coacervation 簡單共聚

一種 polymer，藉由降低溶解度使其析出沉澱，在沉澱過程中包覆藥品。

引發相分離（沉澱析出）的方法：

  • 添加 non-solvent（如加酒精→水溶性polymer降低→析出）
  • 添加 inorganic salts（鹽析效果→polymer析出）
  • 改變溫度（影響溶解度）
  • 改變 pH值（影響溶解度）

Complex Coacervation 複合共聚

兩種相反電荷的親水polymers，電荷被中和→共聚沉澱→包覆藥品。

最典型：帶正電的 Gelatin Type A（調pH到等電點以下帶正電）+ 帶負電的 Acacia（阿拉伯膠）（含大量COO⁻，先天帶負電）

形成 coacervates 後以 Glutaraldehyde 或 Formaldehyde 交聯硬化→分子間形成 methylene bridge→殼收縮硬化→成為一顆顆硬球。

硬化前的微粒膠囊外觀像珍珠奶茶的珍珠，加了 glutaraldehyde 攪一攪後立刻收縮成白白硬硬、非常實心的小球。

調整釋放速率的方法

  • 改變核心藥物：wall polymer 比例（polymer 多→黏度增加→擴散速率降低→釋放減少）
  • 改變包衣聚合物種類（不同材質穿透率不同）
  • 改變微膠囊化方法（噴霧法、coacervation等不同方法→釋放特性不同）

優點

  • 藥品可散布在胃腸道形成大面積分散→增進吸收
  • 可遮蔽藥品苦味（藥物被包住，舌頭接觸不到游離藥物）
  • 藥品給藥劑量可細分成小單位，在胃腸道形成大面積分散
市售例：Micro-K Extencaps（KCl，Wyeth）。名稱解碼：Micro=微粒、K=KCl、Extencap=extended capsule。KCl對胃腸刺激較大，做成ER可減少刺激。

T4Hydrophilic Matrix System 親水性間質系統

藥物與緩慢溶蝕的親水性賦形劑混合造粒後壓錠。製備方式與傳統錠劑最接近（混合→濕粒法或滾壓法造粒→壓錠）。

主要控釋材質（考試核心）

HPMC（Hydroxypropyl Methylcellulose / Hypromellose）
  • HPMC完全分散在配方成分中，以濕粒法或滾壓法製粒，用壓製法製成錠劑
  • 用量 >20% 才能產生滿意的釋放速率（量少→只是黏合劑；量多→整個凝膠化→控釋）
  • 不含HPMC的顆粒提供立即釋放；含HPMC的顆粒提供延長釋放

釋放過程（雙重機轉）

錠片被胃液濕潤
→
polymer水合
→
表面形成凝膠層
→
藥物暴露並釋放初始量
→
水分繼續滲透→凝膠層增厚
→
水溶性藥物：由凝膠層擴散釋放
外層完全水合
→
錠劑核心開始溶蝕
→
藥物繼續釋放
（水不溶性藥物主要靠此機轉）

藥物釋放速率通過 Diffusion（擴散）和 Tablet Erosion（溶蝕） 共同控制。

可製備的劑型

  • 單層錠：全部含HPMC→完整延長釋放
  • 雙層或三層錠：一層不含HPMC（立即釋放）+ 一層含HPMC（延長釋放）
  • 內外核心錠：外核速放，內核延放
  • 延長釋放膠囊（HBS系統）：見下方
不需加塑化劑（塑化劑是給膠囊殼使用的，打錠不需要）。
HBS 系統（Hydrodynamically Balanced System）水合動力平衡系統

膠囊內含 HPMC 粉末/顆粒（+ 主成分）。吃下去到胃→水分進入膠囊→HPMC 吸水水合→膠囊殼溶解後，內容物維持凝膠狀 plug 的形狀→密度低→浮在胃液液面→不隨胃腸蠕動快速向前推進→延長胃部停留時間→藥物持續從凝膠 plug 擴散/溶蝕釋出。

市售例：Madopar® HBS（Levodopa）。Levodopa 主要在小腸上段吸收，HBS讓它在胃停久一點，持續慢慢往小腸上段送。

HBS 膠囊不可打開服用！拆開後內容物散開，無法形成凝膠狀 plug，也無法浮起來，失去緩釋效果。（有些 ER 膠囊可以拆開灌鼻胃管，但 HBS 不行）
市售例：Oramorph SR tablets（AllPharma，morphine sulfate）—利用HPMC親水性間質系統提供延長釋放的專利產品。

T6Complex Formation 複合物形成

藥物與化學藥品產生化學結合（離子鍵、氫鍵等），形成複合物 complex。此複合物視環境 pH，緩慢溶解於體液→藥物慢慢解離→產生藥效。

最常用材質：Tannic Acid（鞣酸 / 單寧酸）

市售的是 salt of tannic acid（tannate salt），提供許多專利產品此種特性。

三大優勢（為何 tannic acid 最常用）：

  • 有大量的 OH 基→與帶正電（鹼性）藥品結合更穩固、不容易解離
  • 來自天然來源（植物）→安全性高、毒性低
  • 有收斂效果→可緩解鹼性藥品（N正帶正電）對胃腸道的刺激

常搭配帶正電（鹼性）的藥品形成 tannate salt，依體液 pH 緩慢解離釋出藥物。

市售例：Rynatan（Wallace）：chlorpheniramine tannate + phenylephrine tannate。名稱中 "-tan" 就是 tannic acid 的暗示。另有 Rynatan Pediatric Suspension、Rynatan Chewable Tablets 等劑型。

T7Ion-Exchange Resins 離子交換樹脂

以陽離子性藥物（cationic drug）為例：通過含有離子交換樹脂的管柱，經由氫離子取代形成複合物，將此複合物洗出後壓錠、包入膠囊或懸浮於水性媒液中。藥物釋放視胃腸道中的 pH 以及電解質濃度而定。

陽離子性藥物（帶正電）

  • → 接在陰離子交換樹脂（帶負電，如 SO₃⁻）
  • → 胃（酸性）H⁺多 → H⁺取代藥物 → 藥物釋出
  • → 胃部釋出 > 小腸
  • 例：chlorpheniramine（N⁺帶正電）

陰離子性藥物（帶負電）

  • → 接在陽離子交換樹脂（帶正電）
  • → 腸（鹼性）負離子多 → 負離子取代藥物 → 藥物釋出
  • → 小腸釋出 > 胃部
常見混淆點：
· 使用不可溶性（insoluble）樹脂，不是可溶性
· 陰離子樹脂（anionic resin）吸附帶正電藥物（正負相吸，不是同性相斥）
· 藥物釋放速率取決於pH 和電解質濃度，不是藥物溶解度

→
②擴散穿透包衣層
→

T8Osmotic Pump 滲透壓幫浦

以滲透壓梯度（不是濃度梯度）為驅動力，將藥物定速推出。與一般釋放靠費克第一定律（Fick's first law，濃度梯度驅動）不同，osmotic pump 靠滲透壓差驅動。

最常用半透膜材質（考試核心）

Cellulose Acetate 醋酸纖維素

半透膜性質：水分可穿過，藥品分子無法穿過→藥品只能從雷射打的小孔（直徑0.4mm）釋出。

EOP vs PPOP

EOP：Elementary Osmotic Pump（簡單型）

  • 核心：單層（藥物 + 滲透壓劑混合）
  • 外覆半透膜，雷射打孔
  • 水進入→溶解滲透壓劑→產生滲透壓→推藥液從孔釋出
  • 適用：水溶性藥物（水不溶者難推出）
  • 後期滲透壓劑減少→推力可能減弱

PPOP：Push-Pull Osmotic Pump（推拉型）

  • 核心：雙層（藥物層 + 推進層，中間彈性膜隔開）
  • 水進入→推進層（高分子滲透劑）吸水膨脹→推擠藥物層→藥物從孔釋出
  • 可釋放水不溶性藥物（懸浮態也能被推出）
  • 推進層始終存在→推力恆定→Zero-order（零級）釋放
  • 市售：OROS system (Alza)、Procardia XL、Glucotrol XL（GITS系統）

常用滲透壓劑（Osmotic Agents）

Methylcellulose (MC) HPMC Sodium CMC PVP Carbopol Polyethylene Oxide (PEO，大分子量PEG)

這些高分子材質可產生滲透壓（π = MRT），且與我們平常用的賦形劑相同，只是在這邊作為滲透壓劑使用。

釋放速率影響因素

✅ 會影響釋放速率

  • 膜的表面積
  • 膜的厚度（最易影響★★）
  • 膜的組成
  • 輸送孔的直徑
  • 滲透壓梯度大小

❌ 不影響釋放速率（重要！）

  • 胃腸道 pH 值
  • 進食狀態（食物）
  • 胃腸蠕動度
  • 媒液pH（體外溶離試驗也無關）
惰性殼（生物惰性成分）在胃腸道保持完整，從糞便排出不代表藥物沒有吸收！要告知病人這是正常現象。（Adalat OROS®、Glucotrol XL 都會排空殼）

（特定時間點 vs 單一總結參數）		 配方開發早期有用；無法反映曲線完整形狀；對監管應用最不有效 最低★

IVIVC 建立條件（FDA指引）

  • 開發不同釋放速率配方（如緩慢、中速、快速三種），分別取得體外溶離圖與體內血漿濃度圖
  • 溶離裝置：優先 USP Type I（網籃）or Type II（槳式）；某些情況可用 Type III（往復式）或 IV（川流槽式）
  • 溶離液pH：不超過 6.8 的水性媒液；水難溶性藥物可加 1% sodium lauryl sulfate
  • 每批至少測 12 粒個別劑量單位的溶離圖
  • 體內研究：受試者空腹狀態為主；6~36 名受試者
  • 研究設計：交叉研究最佳；平行研究也可接受；常用對照治療藥品（靜脈注射液、水性口服液或立即釋放產品）
