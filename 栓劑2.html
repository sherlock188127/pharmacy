簡介與用途

栓劑為放置人體腔體的固體製劑，可產生全身或局部作用，適用於不能內服之病人（如嬰兒、老人等）。

局部作用代表
  • Miconazole 栓劑 → 陰道感染（念珠菌）
  • Bisacodyl 栓劑 → 暫時緩解便秘
全身作用亦可
  • 止痛、止吐、退燒
  • 題目說「只能產生局部作用」 → 錯誤！

劑量計算 — 密度因子法（最常用）
DENSITY FACTOR (DF)
DF = 藥品重量 被置換的基劑重量
= 藥品重量 ÷ (空白栓劑重量 − 含藥栓劑重量 + 藥品重量)
DF > 1 → 藥品重量大於基劑重量
4種計算方法
⭐ Density factor method（最常用）

密度因子法，計算藥品與基劑的替代量

Dosage replacement factor method

劑量置換因子（公式：基劑/藥物）

Occupied volume method

估據體積因子法，V × D = M

Viscosity factor method

黏度因子（較少用）

✅ 結論：栓劑劑量計算與密度、劑量、估據體積有關，其中最常使用方法為密度因子

密度因子法（Density Factor）計算詳解
公式與定義
DENSITY FACTOR
DF = 藥品重量 ÷ 被置換的基劑重量
= 藥品重量 ÷ (空白栓劑重量 − 含藥栓劑重量 + 藥品重量)
其中「空白栓劑重量」= 指沒有藥物時整顆基劑的重量
範例（來自講義）
空白栓劑 = 2g
藥品 = 0.5g
含藥栓劑 = 2.2g
被置換基劑 = 0.3g
DF = 0.5 ÷ 0.3 = 1.6
DF > 1 → 藥品重量大於基劑重量
114-1 考題公式
A = 空白基劑平均重量
B = 每粒栓劑中藥品重量
C = 含藥栓劑平均重量
DF = B ÷ (A − C + B)
答案選 (D)
